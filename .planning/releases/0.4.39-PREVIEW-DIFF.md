**State differences that are not product differences.** The preview's workspace holds one work area, "Op CRAZY ANIMAL", so it shows "Open work area: …" on Get Started and a row under Planning's Local work areas; the candidate's workspace is empty. The candidate's status bar shows **Restricted Mode** and **Secrets are unavailable** because it runs with no secret store (46-07), which the older preview image predates.

## Missing from the candidate

Nothing the owner reviewed is missing from the second candidate.

The first candidate lacked two Documentation topics:

- **Contributing** (`CONTRIBUTING.md`);
- **Environment packs** (`docs/staff-env-packs.md`).

They came from Codex `535dab5a` ("native reference tabs and Defence Edition trails", on `feat/theia-team-studio-preview`). Its documentation builder bundled every docs-site page plus `CONTRIBUTING.md`. Phase 46-01 (#187) replaced that builder with an explicit list of guides and the Docker context allowlist, and left these two out. The audit marked `535dab5a` as fully done, so it missed them.

#202 restores both. It came from `fix/release-0.4.39-documentation-topics`, is on main, and is in this release.
