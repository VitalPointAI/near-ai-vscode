# Delivery audit — 2026-10-26

Independent audit of phases 1–6 against `REQUIREMENTS.md`, the roadmap, and every
PLAN.md, judged on the shipped code (v0.3.1) and on what a user can actually reach.
SUMMARY.md and VERIFICATION.md files were treated as claims, not evidence.

Status key: **Works** (real and reachable) · **Partial** · **Unreachable** (code
exists, nothing invokes it) · **Fake** (placeholder or invented contract) ·
**Missing** · **Superseded** (replaced by a later user decision).

## Verdict

The NEAR AI chat path is real: project-scoped keys in SecretStorage, the model
catalog, streaming, cancellation, retries, activity history, and org/project cost
attribution. Almost everything else the roadmap promised is a tested service with
no working path from the UI, or depends on an API contract that does not exist.
The three findings that matter most:

1. **Open-GSD workflows do not run.** The bridge spawns `codex exec … $gsd-<cmd>`:
   `codex` is not on PATH, stdin is never closed, no sandbox is set, no arguments
   can be passed, and the progress/prompt events it parses are an invented
   protocol nothing emits. GSD questions dead-end.
2. **GSD would not use NEAR AI even if it ran.** `codex exec` uses the user's Codex
   provider (OpenAI on this machine), bypassing the NEAR AI key, privacy checks,
   cost tracking, and TEE claims.
3. **No safety layer is on the main paths.** Chat and `@nearai` send the whole
   conversation to the provider with no privacy preflight, policy, budget, or
   audit. Emergency stop, spend limits, local-only mode, and the
   `nearAi.actionPolicy` setting have no effect.

## By area

### Setup, keys, profiles (AUTH, MODEL-04)
- Works: AUTH-01, AUTH-03 (scoped SecretStorage keys), setup wizard and profile switching (fixed today in `3e332a8`), SEC-02 (no `~/.near-credentials` access).
- Missing: removing a profile/key (no command), reusing an organization profile across projects, legacy key import (handler, no UI).
- Fake: AUTH-02 NEAR account sign-in. The `nearAccount` auth mode breaks chat if selected.

### Models and cost (MODEL, COST)
- Works: catalog with pricing from `/v1/models` (fixed today), streaming, retries.
- Fake: COST-01 actual cost (wrong endpoint); sidebar never shows estimates (fresh client per send has no pricing cached).
- Missing: MODEL-02 local OpenAI-compatible runtimes (no plan ever covered it); MODEL-03 local-vs-cloud labels; COST-02 user spend limits and emergency stop; `budgetRemainingUsd` never computed.

### Chat workspace and GSD bridge (CHAT, GSD, UX-01, CTX)
- Works: CHAT-01 streaming chat with cancel, slash-command launcher, CHAT-05 status line (agents/cost fields read keys GSD never writes).
- Fake: GSD-01 command execution, CHAT-02 progress metadata, CHAT-03 structured prompts.
- Partial: CHAT-04 history (reopen shows a summary only), GSD-02 artifact links (Tools tab only; sidebar ignores them).
- Missing: UX-01 branded animated indicator (dropped in the sidebar redesign; never built in Tools), next-action buttons after runs, CTX-01–04 context monitor/thresholds/restore (only a manual checkpoint that nothing reads back).
- Updater: GSD-03/03a superseded by the 2026-10-26 decision (install only when a GSD command runs in a project set up with the extension); detection bug above; GSD-05 has no lock, rollback, or cancellation, and installs an unpinned `@latest`.

### Agents, routing, approvals, privacy (AGENT, ROUTE, SAFE, PRIV, ONB-04)
- Unreachable: ONB-04 team questionnaire, AGENT-01/04/05/06/07, ROUTE-01/02, PRIV-03/05, ResumableExecution.
- Fake: team invocation only writes a "running" ledger entry, never calls a model; fleet view always shows 0 agents.
- Partial: SAFE-01/02 and PRIV-02/04 apply only to image generation and attachments; analytics filters and export work on chat data.
- Missing: UX-02 quiet-mode control (host handler, no UI).

### Team studio, multimodal, generation, memory (TEAM, MULTI, GEN, MEM)
- Works (service level): team preview, import/export, tamper-safe bindings, memory approval wiring, graph/table rendering, attachment staging.
- Broken: TEAM-01 create (ID mismatch); TEAM-02 member editing (no editor); bind/invoke always fail.
- Fake: MULTI-02 operations return canned labels; no provider call (NEAR serves Whisper; no transcription client).
- Unreachable: GEN-01 image generation fails closed against the live catalog (expects invented capability fields); video unsupported.
- Unreachable: MEM-02/03 nothing writes or reads facts; the graph is always empty.

### Wallet, staking, entitlement (AUTH-04, COST-05, STAKE-01–03)
- Fake end to end: no wallet adapter, no callback handler, no RPC reader, no config source, no UI that sends wallet actions. Could not have been switched on without new code.

### Release and documentation (PKG, SEC-03, TEST-01)
- Works: VSIX build and release check.
- Gap: release check does not require `media/chat/*`.
- False published claims: README and SECURITY.md say a privacy check runs before each request (not on chat); SECURITY.md says NEAR sign-in token exchange is "prepared in the UI" (no UI), cites v0.1.0, GIF assets, and stale release counts, and omits that GSD runs through Codex's provider and that the updater runs an unpinned `npx`.
- Tests that give false confidence: source-text regex tests (`chatBridge.test.ts`, `staking.test.ts`, `walletAuthorization.test.ts`, `contextGraphProtocol.test.ts`), fake GSD process emitting the invented protocol, team/generation/multimodal tests that seed state production never creates or mock invented catalog fields, `workspaceIsolation.test.ts` fake `npm list` hiding the updater bug.

## Recommended order

1. **Patch release now:** fix updater detection; correct README/SECURITY.md claims; remove the `nearAccount` option and the dead staking entry points; add `media/chat/*` to the release check; actual cost via `/v1/billing/costs`; sidebar cost estimates.
2. **Make GSD real on NEAR AI** (decision needed: drive Codex with a NEAR provider override and its real JSON/interactive protocol, or run GSD workflows natively against NEAR AI).
3. **Put the safety layer on every outbound path:** preflight + policy + budget + audit for chat, `@nearai`, and GSD; emergency stop; spend limits; local-only mode.
4. **Make the advanced features honest:** either finish (teams that run, real multimodal via Whisper/vision, image generation from the real catalog shape, memory written by runs) or hide them until they work.
5. Local runtimes (MODEL-02/03), context continuity (CTX), and staking only after the above.
