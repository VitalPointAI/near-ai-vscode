## Decisions

- **Memory in KB (from RESEARCH Pattern 10):** disabled, not encrypted: findings belong in the base (D-08). Refusal copy: `Project memory is off in knowledge-base projects. Findings are recorded in the knowledge base instead.`
- **At-rest key:** `atRestKey(localSecretsRoot, kbId, purpose: 'attachments' | 'generated')` = HKDF-SHA-256(localSecretsRoot, salt = utf8(kbId), info = "near-ai-kb/at-rest/v1|" + purpose, 32); sealed file = `NKBA` magic + 12-byte nonce + ciphertext + 16-byte tag, AAD = utf8(purpose + "|" + artifactId).
- **Fail closed:** `atRestCodecFor(root)` returns the codec registered by an unlocked `KbService.open`; when `isKnownKbRoot(root)` is true and no codec is registered, intake and generation refuse to persist with a clear error.
- **Publication:** explicitly approved publication of a generated image to a user-chosen workspace path remains the user's choice (existing approval flow) and is out of this plan's scope; the managed copy under .planning/.near-ai/ is sealed.
