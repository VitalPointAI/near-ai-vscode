<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Open-GSD/provider events -> card mapper | External/runtime text is transformed into user-visible progress. |
| webview prompt response -> host | Untrusted choice/free-form answers and session identifiers cross into the host. |
| session context -> prompt/progress UI | Stored operational data is displayed without private prompt or secret disclosure. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-07 | Spoofing | prompt response handler | high | mitigate | Bind answers to active session/prompt IDs and reject stale, unknown, or cross-session responses. |
| T-03-08 | Information Disclosure | progress-card mapper | high | mitigate | Redact runtime output and prohibit raw prompts, environment values, credentials, and hidden reasoning from card payloads. |
| T-03-09 | Tampering | resume/cancel controls | medium | mitigate | Require an active stored session, make cancellation idempotent, and resume only the recorded continuation state. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package install is planned; rely on the official-runtime boundary and legitimacy controls already established in 03-03. |
</threat_model>
