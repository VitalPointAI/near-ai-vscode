<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Open-GSD child output -> extension host | Runtime-controlled JSON and text become typed lifecycle data. |
| Extension host -> webview | Operational metadata crosses into untrusted rendered UI. |
| Lifecycle event -> local activity ledger | Runtime values are persisted for history and reopen. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-10 | Tampering | runtime event parser | high | mitigate | Parse only an explicit metadata allowlist, validate bounded scalar types, and ignore malformed lifecycle fields without changing command control flow. |
| T-03-11 | Information Disclosure | progress/activity metadata mapper | high | mitigate | Reuse safe text redaction, omit raw prompt/environment/credential values, and assert secret-shaped and unrestricted-output payloads never reach cards or serialized activity. |
| T-03-12 | Spoofing | approval/retry lifecycle display | medium | mitigate | Treat approval, attempt, and terminal state as typed runtime metadata and preserve event ordering/session binding rather than trusting arbitrary display text. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installation is planned; retain the established official-runtime package boundary. |
</threat_model>
