# Plan 03-02: GSD Progress, Motion, and Next-Action Guidance

**Objective:** Make GSD state legible to new and experienced developers while ensuring every completed report leaves the user with a recommended next action or a direct command path.

**Requirements:** ONB-02, ONB-03, CHAT-03, CHAT-04, CHAT-05, GSD-03

## Tasks

- Parse the project planning state into a compact status line showing completion, phase, plan, execution state, agents, and cost context.
- Add NEAR motion states for reasoning, streaming, waiting, completion, and failure with reduced-motion and accessible status behavior.
- Add a searchable Open-GSD command launcher covering start, workflow, context, review, and management commands.
- Add post-response recommended-next-action controls with one-click continuation and progress refresh.
- Link setup, command selection, and continuation guidance so users unfamiliar with GSD can proceed without memorizing slash commands.

## Verification

- Every completed or failed response leaves an actionable next-step control visible.
- The command launcher opens the selected GSD workflow in chat with project context.
- Status and motion states do not reveal private chain-of-thought and remain understandable with reduced motion enabled.
