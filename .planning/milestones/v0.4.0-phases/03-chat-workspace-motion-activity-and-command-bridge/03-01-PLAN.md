# Plan 03-01: Chat Workspace and Provider Streaming

**Objective:** Provide a working Near AI chat surface that streams model output, lets developers select a model, and keeps provider/authentication boundaries inside the extension host.

**Requirements:** CHAT-01, CHAT-02, MODEL-01, PRIV-01

## Tasks

- Create a VS Code webview chat workspace with accessible message rendering, composer controls, cancellation, and model selection.
- Connect the webview to the typed NEAR AI client through extension-host message handlers; never expose API keys to the webview.
- Surface provider errors as actionable, redacted messages and route missing credentials to the visual setup flow.
- Add unit and host-boundary checks for message routing and model catalog behavior.

## Verification

- A configured user can send a prompt and see ordered streamed deltas in the chat.
- A missing key routes to setup without making a provider request.
- Stop cancels the active request and the UI returns to an actionable state.
