## Trust Boundaries

| Boundary | Description |
|---|---|
| Durable activity JSON ↔ extension host | Workspace-controlled persisted event data is rehydrated into host-owned session, analytics, and history records. |
| ActivityStore ↔ analytics/history consumers | Normalized attribution crosses into cost, token, timeline, drill-down, and export paths and must remain session-owned. |

## Least-Privilege Constraints

- Persisted event fields may contribute bounded operational metadata only; they cannot choose the owning organization/profile/project.
- Only the host-created session attribution snapshot may populate rehydrated event ownership.
- Legacy or malformed session attribution falls back to the existing explicit unknown bucket and never consults current selection state.
- Regression fixtures must remain non-sensitive and must assert redaction of credential, prompt/context, command, and path-shaped content.
