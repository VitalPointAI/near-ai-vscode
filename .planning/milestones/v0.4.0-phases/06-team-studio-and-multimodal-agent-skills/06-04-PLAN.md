<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| webview -> extension host | Untrusted generation parameters, model IDs, operation IDs, and publication requests enter privileged orchestration. |
| team skill -> capability router | A reusable team may request a powerful generation operation that must remain bounded by allowlisted capability metadata. |
| extension host -> provider API | Prompts, approved media handles, credentials, and cancellation signals cross to an external provider only after policy checks. |
| generated artifact -> publication/export | Generated output can become an externally visible file or shareable artifact only after separate approval and privacy checks. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-17 | Elevation of privilege | generation skill and capability router | critical | mitigate | exact operation/modality/model/privacy capability checks, no chat fallback, and host-derived metadata |
| T-06-18 | Information disclosure | provider requests and generation analytics | critical | mitigate | raw prompt/media exclusion by default, explicit content handles, redacted activity, and secret-safe errors |
| T-06-19 | Tampering | model metadata and provider lifecycle | high | mitigate | immutable capability/price snapshots, official adapter contracts, status validation, and fail-closed unknown states |
| T-06-20 | Denial of service | asynchronous generation polling | high | mitigate | bounded polling, AbortSignal cancellation, timeout, budget reservation, emergency stop, and restart pause |
| T-06-21 | Repudiation | generation approval/publication | high | mitigate | separate exact-scope approval fingerprints, attribution snapshots, request IDs, lifecycle audit, and host recomputation |
| T-06-22 | Spoofing | publication destination and generated artifact | high | mitigate | managed artifact IDs, path containment, provenance/lineage checks, and separate publication authorization |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | no new package-manager dependency; if implementation discovers an install is required, stop for package legitimacy review and a blocking human verification gate |
</threat_model>
