<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| webview -> extension host | Untrusted attachment references, modality requests, and user-visible IDs cross into privileged file and policy handling. |
| local filesystem -> intake service | Files may contain secrets, active content, malformed media, deceptive MIME values, or paths outside the selected workspace. |
| intake service -> provider adapter | Approved metadata or raw-content handles may cross to a provider only after capability, privacy, approval, and budget checks. |
| derived artifacts -> activity/analytics/export | Derived metadata is observable; raw media and sensitive content must not cross this boundary by default. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-11 | Tampering | attachment staging and hashes | high | mitigate | realpath containment, detected-content validation, immutable content hashes, and provenance mismatch rejection |
| T-06-12 | Information disclosure | chat bridge, activity, analytics, exports | critical | mitigate | opaque IDs, safe previews, raw-content exclusion types, redaction tests, and host-side serialization gates |
| T-06-13 | Elevation of privilege | modality operation dispatch | high | mitigate | explicit operation capabilities, PolicyGate checks, exact approvals, and no implicit raw-content access |
| T-06-14 | Denial of service | media parsing and derived-artifact ledger | high | mitigate | pre-parse size limits, bounded records, bounded lineage fan-out, cancellation, and emergency stop |
| T-06-15 | Spoofing | provenance and derived lineage | high | mitigate | content fingerprints, source IDs, route/model snapshots, and immutable lineage edges |
| T-06-16 | Repudiation | multimodal lifecycle | medium | mitigate | redacted audit events with operation IDs, approval fingerprints, attribution, and deterministic reason codes |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | no new package-manager dependency; if implementation discovers an install is required, stop for package legitimacy review and a blocking human verification gate |
</threat_model>
