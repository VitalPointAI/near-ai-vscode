# Data management and knowledge graph interface reference

## Why This Matters

The owner wants the data management and knowledge/context graph interfaces to resemble the interface in [knowledge.mp4](../../docs/specs/knowledge.mp4), including similar animations that show incoming data being ingested and then settling into the part of the graph where it belongs.

Use [knowledge 2.mp4](<../../docs/specs/knowledge 2.mp4>) as a second interface reference, especially its rotating brain-shaped cloud representing the graph.

## When to Surface

Review both videos before drafting the UI design for Phase 88 (governed store and data map), Phase 96 (search, context graph, entity pages and ask), and related Phase 97 views. Carry the relevant layout and interaction patterns into those UI specs. Specify how the graph rotates and how incoming items move from ingestion to placement. Show which relationships determine where each item lands.

## Scope Estimate

Choose the concrete interface details during phase design.
