<objective>
Move run markers and run checkpoints into the state home and make run liveness correct across editors: a writer identity plus a heartbeat replace the pid check for other editors, so desktop VS Code never mistakes a live code-server run for a cut-off one and auto-resumes it (double spend). Make activity.json safe with two writers.

Purpose: as soon as two editors share one project folder (plan 03), the pid rule is wrong across the container's pid namespace (Pitfall 1). This fix must land before any second editor reads shared markers.
Output: modified runMarkers.ts, checkpoints.ts, activityStore.ts, agentSession.ts, chat.ts, extension.ts, stateHome.ts and three test files.
</objective>
