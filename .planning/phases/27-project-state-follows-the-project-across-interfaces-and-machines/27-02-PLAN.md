records.ts (SYNC-05): canonicalJson serialises with object keys sorted at every depth, arrays in order, UTF-8, no whitespace, and throws on undefined, functions, NaN and Infinity; revOf = first 16 hex characters of sha256(canonicalJson(body)). MERGE_POLICY: 'comparison' and 'checkpoint' are 'fork'; 'spend' is 'union'; 'marker', 'choice', 'profile', 'secret', 'pickup', 'thread-meta', 'thread-context' are 'lww'; 'tombstone' is handled by the tombstone rule. parseRecord validates kind, rev (16 hex), at (ISO time), writer (/^[a-z0-9-]{4,80}$/) and id (at most 200 characters, no path separators, no NUL) and returns undefined for anything else.

threadEntries.ts (D-07, D-12): entryId = first 26 characters of lowercase Crockford base32 of sha256 over (parent or empty) + newline + role + newline + canonicalJson(body). unionEntries keys by id and keeps the first seen copy (copies with one id have identical bodies by construction). threadLines: build the tree by parent; the newest leaf is the maximum by (at, writer, id) compared lexicographically; main is root-to-that-leaf; every other leaf's path after its divergence from main becomes a branch with forkAt = the last shared entry id, branches ordered by their first entry's (at, writer, id). Entries whose parent is unknown (partial delivery) attach as their own branch with forkAt = their parent id, so they are still shown. capToolResult implements D-12 with TOOL_RESULT_CAP_BYTES = 2 * 1024 * 1024, cutting with Buffer.byteLength and backing off to a UTF-8 character boundary.

merge.ts: mergeRecord follows 27-RESEARCH.md "Deterministic record merge" with the per-kind policy: divergent 'lww' kinds keep the newer by (at, writer, rev) and return no fork; divergent 'fork' kinds also return fork = the older with id forkId(id, rev) = id + '~' + first 12 hex of sha256(id + rev). A tombstone record replaces a same-id record only when its at is newer. mergeRecordSets applies mergeRecord per (kind, id) over two arrays and returns a sorted array (by kind, then id). unionLog merges spend-style lines by id keeping the highest v (ties by canonical JSON). Write the tracer behaviors in src/test/threadMerge.test.ts.
