<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| extension -> git subprocess | arguments, environment and config reach a program that runs hooks and helpers |
| remote host -> mirror | refs, trees and blobs fetched from a host anyone with push rights can change |
| project repository -> transport | the person's repo config (remotes, insteadOf) is read |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-42 | Elevation of privilege | hooks, fsmonitor or ext transport executing code during sync | high | mitigate | SAFE_GIT_CONFIG on every call, empty hooksPath, protocol.ext.allow=never, '::' addresses refused (Tasks 1, 3) |
| T-27-43 | Information disclosure | the person's identity in commits or push certificates | high | mitigate | identity only via commit-tree env; runner refuses without it; gpg signing off; sentinel test (Task 2) |
| T-27-44 | Tampering | inherited GIT_DIR or GIT_WORK_TREE redirecting writes into the person's repo | high | mitigate | stripped environment; explicit --git-dir; snapshot test of the user repo (Tasks 1, 2) |
| T-27-45 | Tampering | hostile tree entry names | medium | mitigate | readTree accepts only TREE_NAME blob entries |
| T-27-46 | Information disclosure | credentials in messages | medium | mitigate | redactGitMessage plus redactSecrets on every message (Task 3) |
| T-27-47 | Tampering | repository-chosen push destination | high | mitigate | no repository-readable setting chooses the remote (D-09 defers the setting); validateRemote on every value (Task 3) |
| T-27-48 | Denial of service | hanging git or huge blobs | medium | mitigate | timeouts with kill-tree, stdout caps, mirror lock with stale detection |
| T-27-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package is installed |
