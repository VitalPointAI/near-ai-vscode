No external API integration: the phase adds a local, offline gate in front of calls the extension already makes (agent tool calls, MCP tool calls and model requests through the existing NearAiClient) and signs its policy with the existing node:crypto signer; it calls no new third-party service, SDK or HTTP API. The only network use it touches is the existing response attestation check against NEAR AI Cloud (src/services/attestation.ts), which it reuses unchanged and runs out of band. "OCSF" and "API Activity" in the plans name a record shape, not a service the extension calls.
