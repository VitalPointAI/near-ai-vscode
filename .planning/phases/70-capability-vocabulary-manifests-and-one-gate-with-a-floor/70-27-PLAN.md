<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored and synced thread meta -> the badge a person sees | another machine's or an edited copy of the meta can carry any record |
| docs -> people deciding what to share | an overstated badge description leads to misuse |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-70-99 | Tampering | an edited or synced trust record raising a badge | medium | mitigate | parseTrustRecord drops malformed records; the merge keeps the weaker state for one key (Task 1) |
| T-70-100 | Repudiation | docs describing the badge as stronger than its checks | medium | mitigate | constants compared character for character, NOT_CHECKED_IN_EDITOR stated, the old action's wording removed (Task 3) |
| T-70-101 | Denial of service | the e2e change leaving a cloud profile selected for later tests | low | mitigate | the test selects the local profile again and clears the provider cache (Task 2) |
| T-70-SC | Tampering | npm installs | high | mitigate | No package is added |
</threat_model>
