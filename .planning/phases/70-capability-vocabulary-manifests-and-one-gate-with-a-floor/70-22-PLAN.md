<objective>
Make the session high-water mark live: it rises with what agents read, is shared with sub-agents, marks everything the session writes, keeps calls that can send data off this computer refused at strict labels, and refuses the next model request when the label no longer allows the model. Plan 23 keeps it with the chat, shows it and adds the person's recorded way down; both ship in PR 4c.

Purpose: PR 4c (D-49). CLAS-04 (the mark, inheritance, sub-agents), CLAS-01 (tool output carries labels), CLAS-06 (a rising mark changes where the next request may go), GATE-07 (raises recorded), D-26, D-29, D-31, D-54.
Output: `SessionMark`, the raise at the shared hook, search raises, the shared off-machine predicate and `label.network-at-mark`, write inheritance, run-local marks for runs with no chat, `gateMark.test.ts`.

Corrections from the 2026-11-17 audit, applied here: the network check uses `commandMaySend` and `callSendsOffMachine` (fail closed, PR #76) instead of the older `NETWORK_COMMAND` regex, which also covers remote MCP tools; the raise happens at loop.ts's credential-read hook before `tool.run` (lines 785-786 on main with #76), not in `gateToolCall` after the call; decide() does not change: the adapter works out the verdict, and plan 20 already made decide() read it when effects are unknown; a raise has its own event id (`label.mark-raised`, plan 19) and the record's `mark` field; Glob and Grep filtering moved to plan 20, this plan only raises from what they return; runs with no chat get their own mark; an automatic write never signs an unverified map.
