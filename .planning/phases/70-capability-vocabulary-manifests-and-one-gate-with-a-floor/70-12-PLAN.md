<objective>
Put the one gate in front of every chat run's tool calls and its sub-agents', start it at activation, record every decision to the per-project log, and make approval cards a transport into it. With a valid bundle, decisions stay exactly as today (shadow floor); with an invalid one, the gate fails closed.

Purpose: GATE-04 (one gate, cards are transport), GATE-07 (every decision recorded), OFFL-02 (the fail-closed bundle state now reaches real decisions), D-08, D-09, D-10, D-43. Plan 13 gates the remaining execution paths and adds the enumeration test.
Output: `src/gate/host.ts`, `src/agent/gateAdapter.ts`, the gate call in `executeCall`, `registerGate` at activation, gated sub-agents, cards as transport, the first cases of `gateEnumeration.test.ts`.

Size note: the tracer task touches eight files because it runs one call through every layer it changes (activation, host, chat, conversation, loop, adapter, record); each change in it is a few lines except the adapter.
</objective>
