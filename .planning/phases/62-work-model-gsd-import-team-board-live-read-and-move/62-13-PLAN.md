<objective>
Let people add bugs, chores and spikes on the board and edit their own. The form validates as the person types, the host re-validates, refuses secret-like text, and writes one signed item.created (or item.updated and item.estimated for an edit) that every client then shows. The tracer has a developer add a chore through the real form script and the real host, and the owner's clone materialise it with the developer as its creator.

Purpose: D-14 (items can be created on the board this phase, with permissions from the 6.3 matrix) as part of BOARD-01, with BOARD-03 permission checks.
Output: `media/board/form.js`, host handlers in `boardView.ts`, `boardForm.test.ts`, `teamBoardItems.test.ts`.
</objective>
