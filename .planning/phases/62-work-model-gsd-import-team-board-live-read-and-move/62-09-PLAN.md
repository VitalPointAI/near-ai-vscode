Created here (client API on window, consumed by menu.js, drag.js, detail.js, form.js):
```javascript
window.NearAiBoard = {
  post(message), announce(text), icon(name), layout(),            // 'list' | 'kanban'
  model(), cardData(id), cardElement(id), focusCard(id),
  setPending(id, text), showRefusal(id, columnLabel, reason), clearRefusal(id),
  setFilter(name, value),                                          // name: 'mine' | 'ready' | 'blocked' | 'requirement' | 'phase'
  onRender(listener), onMessage(type, listener),
  registerMenu(open), openMenu(id, opener), registerDetail(open), openDetail(id, opener), registerForm(open), openForm(itemId)
};
```
