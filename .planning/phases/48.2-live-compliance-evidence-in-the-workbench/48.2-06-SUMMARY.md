# Phase 48.2 Plan 06: Site evidence formats, the site-key-signed trust document and key versions Summary

Site evidence now has one engine definition: a trust document your site key signs names the collector's Transit key versions and the operators' keys with their purposes and dates; the live feed, the operator's export, rescan and agreements each verify only through it, for their own purpose, and become observations dated at their own evidence time; a key rotation keeps working while both versions are listed, and nothing future-dated or outside the allow-list is used.

## Sample formats (for the wave 3 gate; from the tests, keys shortened)

Trust document:

```json
{ "format": "sterling-evidence-trust/1", "site": "site-a", "issuedAt": "2026-11-25T11:00:00.000Z",
  "signers": [
    { "id": "collector", "role": "collector", "purposes": ["site-evidence-live"], "notBefore": "...", "notAfter": "...",
      "versions": [{ "version": 1, "publicKey": "<raw Ed25519, base64url>" }, { "version": 2, "publicKey": "..." }] },
    { "id": "operator-1", "role": "operator", "purposes": ["site-evidence-export", "site-rescan", "site-agreements"], "notBefore": "...", "notAfter": "...", "publicKey": "..." } ],
  "freshness": { "vulnerability": { "ageingAfterHours": 72, "outOfDateAfterHours": 240 } } }
```

Live feed payload (inside the signed-payload envelope, purpose `site-evidence-live`):

```json
{ "format": "sterling-site-evidence/1", "site": "site-a", "generatedAt": "2026-11-25T11:59:00.000Z", "keyVersion": 1,
  "groups": { "openbao": { "collectedAt": "2026-11-25T11:55:00.000Z", "sealed": false, "type": "pkcs11" },
              "nodes": { "collectedAt": "2026-11-25T10:30:00.000Z", "count": 3 } } }
```

No pass field anywhere, no user names, emails, tokens, private keys, log lines or policy text: ids, counts, hashes, digests, booleans, times and alert names only.
