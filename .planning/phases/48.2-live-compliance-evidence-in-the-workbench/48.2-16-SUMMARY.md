## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Site files could take about a minute to reach the view**
- **Found during:** Task 2 ("Site layered" failed at 40 seconds).
- **Issue:** `refresh()` read the mount only when 30 seconds had passed since the last read. The page's own reads (getEvidence, the long poll) land between interval ticks, so the next tick found the mount "not due" and skipped it; the file was read one tick later, up to about 60 seconds after it landed. The unit tests did not see it because their fake timers make every read land exactly on a tick.
- **Fix:** the interval tick always reads (`check(true)`); callers' reads keep the 30-second rule.
- **Files modified:** `workbench/extension/src/node/sterling-evidence-service.ts`, `workbench/test/evidence-service.test.ts` (one case: a read at 5 s, a file at 5 s, read at the 30 s tick).
- **Commit:** 684a4425

**2. [Rule 3 - Blocking] `runPlaywright` takes extra arguments**
- `workbench/test/helpers/docker.ts` is not in the plan's files. One container per case needs `--grep`; the new parameter defaults to none, so the other suites are unchanged. Commit b61671b1.
