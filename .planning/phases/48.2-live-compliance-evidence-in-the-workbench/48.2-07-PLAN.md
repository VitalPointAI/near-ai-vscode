<objective>
Put each release's evidence inside the image that ships, every release including hotfixes, in an order that keeps the SBOM honest, and sign it (D-15, D-16, D-19). The image job builds the software image S, takes its SBOM and scan, assembles the evidence, builds R = S plus one data-only layer, and proves that with one script. Publish signs the evidence manifest with the supplier release key in key mode and publishes it with the public key.

Purpose: a fresh install always has its release's evidence; the image's own signature cannot be inside it, so the manifest is signed separately.
