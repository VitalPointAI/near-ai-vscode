## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `node:test` through `scripts/run-tests.mjs` (TypeScript by Node type stripping in `compliance/`; esbuild-built tests in `workbench/`; `.mjs` in `deploy/`, `docs-site/` and `scripts/test/`); Playwright against the built image for the one focused browser check (48.2-16) |
| **Config file** | none; `npm --prefix compliance ci --ignore-scripts` and `npm --prefix workbench ci --ignore-scripts` once per checkout; helm and cosign from `sh compliance/ci/install-tool.sh helm compliance/out/tools` and `... cosign compliance/out/tools`; docker or podman for the container runs |
| **Quick run command** | `systemd-run --user --scope -q -p MemoryMax=4G -p MemorySwapMax=0 choom -n 1000 -- timeout 300 env PATH="$HOME/.nvm/versions/node/v26.13.1/bin:$PATH" node scripts/run-tests.mjs <the one mapped test file>` (deploy tests with `HELM=compliance/out/tools/linux-amd64/helm COSIGN=compliance/out/tools/cosign`) |
| **Full suite command** | under `flock "$HEAVY_LOCK"` with 6G and 1800 seconds, one at a time: `npm --prefix compliance test`; `node scripts/run-tests.mjs deploy/test/*.test.mjs scripts/test/*.test.mjs docs-site/test/*.test.mjs`; `npm --prefix workbench run lint && npm --prefix workbench test`; `npm --prefix workbench run test:container` only where a plan says so; plus `node compliance/src/cli.ts validate`, `hosted-docs --check` and `node scripts/build-road-to-production.mjs --check` |
| **Estimated runtime** | about 300 seconds without the container suite; the container suite about 15 minutes |

Where a check blocks: the docs-site tests and `build-road-to-production.mjs --check` in the required `docs` job (48.2-02's mode test is there); the deploy tests, including the cosign parity test and the trust-anchor write invariant, in the `deploy` job; the workbench suite in the `workbench` job; the workflow-file tests in `test`; the layer proof in the release workflow itself. The `compliance` job is not a required check, so no 48.2 evidence rule names a compliance test (48.1 D-05).

---

## Sampling Rate

- **After every task commit:** the task's own verify command (one mapped test file, or the workbench unit suite for workbench tasks).
- **After every plan wave:** the full suite once, on the wave's combined branch before its pull request.
- **Before `/gsd-verify-work`:** the full suite once (48.2-15 Task 2), the container suite once (48.2-16, and 48.2-07 Task 1 when the Dockerfile changed since), and the side-by-side release-candidate check with the lab's refused trust write (48.2-15 Task 3).
- **Max feedback latency:** 300 seconds outside the container runs.
