# Phase 48.2 Plan 05: The release evidence folder, its writer and the release-evidence command Summary

One command, `release-evidence`, assembles a release's whole evidence folder (bundle dashboard and judgement, image SBOM, Grype scan and database status, compliance package and checksum, road-to-production page, gap register) under a `sterling-evidence/1` manifest written last, and the scan becomes an `image-scan` observation that ages from its database's build date: Current on 26 November, Ageing on 28 November and Out of date (Stale) on 21 December for a database built on 20 November.

## Folder listings (for the wave 3 gate)

Full form (`--bundle --package --road-to-production --gaps`), manifest `bundle: included`, `package: included`:

```
bundle/dashboard/dashboard.json
bundle/dashboard/judgement.json
bundle/dashboard/text/...            (the official control text, when the bundle has it)
documents/gaps.json

```

```

```
