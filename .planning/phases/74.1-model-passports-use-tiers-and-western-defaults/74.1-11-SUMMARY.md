# Phase 74.1 Plan 11: Exceptions for chat you review Summary

Under your organization's rules, the policy editor gains "Exceptions for chat you review": each research-only model has "Ask to allow for chat you review"; the draft card opens with the legal flags first ("On the US Entity List." for GLM), takes projects, labels, conditions, a mission benefit, the named person and an end date of at most 90 days, and the review card shows exactly what will be signed. "Sign and save the request" signs with this computer's key as the named person's inner signature and saves a request file for your organization; nothing changes on this computer and no policy edit is recorded. With no organization layer the section says so and drafts nothing, whatever the page asks. Once your organization's rules carry the record, the trust line reads "Allowed for chat you review by Avery Chen until 25 Dec 2026", with no self-signed form.

Every checkbox row is one `label` wrapping its `input`, box first, an 8px gap, a 16px box, a row at least 24px high, and the box centred on the first line. `workbench/test/e2e/sovai-checkboxes.spec.ts` renders `base.css` and `policy.css` in Chromium with the draft card's Projects, Labels and Conditions rows (one label wraps) in the light and the dark theme and measures each row: box centre within 1px of the first line's centre, 8px gap, 16 by 16, at least 24px, and a click on the text toggles the box. Run locally with Playwright 1.65.0: 2 passed. It runs in CI with the container suite's Playwright (it needs no workbench: the page is set from the files).

**[Rule 1] The UI-SPEC's verbatim CSS failed its own acceptance, so the rule was corrected.** The render test measured the verbatim rule 3.75px off: a one-line label's text was centred in the 24px row while the box was pinned to the first line's top, and the box's `1lh` read the input's own `normal` line height. The rule now starts box and text at the top of the row, pads a one-line row to 24px, and gives the box `line-height: inherit`. 74.1-19's workbench copy of the rule should take this version.
