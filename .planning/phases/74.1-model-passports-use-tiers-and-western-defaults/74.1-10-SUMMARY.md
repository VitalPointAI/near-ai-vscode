# Phase 74.1 Plan 10: The cyber harness and Compare Models in the research lane Summary

Every scan role call and every Compare Models task request now runs in a research-lane route (research only), so records say `lane: t0` and an abliterated or PRC-origin model is allowed there under enforce. The fixed fallback model is gone: with no chosen and no abliterated model, the cyber panel asks the person to choose and Run waits. The panel opens with the research workspace banner and the sentence that scans are not isolated in a separate machine, and refuses a folder target inside an open project (Q3). Compare Models offers a job only when the model's approval covers it, says why when it does not, and the host refuses a crafted apply.

- **c0f6a116** (Task 1): `CYBER_USE` on both cyber paths (`cyberAssembly.ts` with or without a gate runtime, and `cyberHandoff.ts`); no `z-ai/glm` literal and no chat-tier fallback; the banner card (`.lifted`, 3px warning bar, `beaker` and `info` icons) first in the cyber header, with `base.css` now loaded by the cyber page; the Q3 check in `attachCyberPanel`'s Resolve scope; the page's model select with the choose option and Run disabled until a model is chosen; the literal scan's exception removed.
