# Phase 74.1 Plan 04: Every refusal, the exception, the licence rule and the models that would pass Summary

Under enforce every passport gap now refuses with its own sentence in the refusal form, naming the model, the uses in the glossary's words, the date, the places in the Runs on words, the person who signed an ended exception, the models that would go instead, and your organization's security contact. A non-commercial licence is research only off a vendor's own service; a self-signed exception covers nothing; nothing is ever moved to another model by itself.

## What changed

- `models.ts`: `NON_COMMERCIAL_LICENCES` (D-06's fixed list) and `passportCovers` in the order status, tier (`acceptance-expired` for an ended exception), licence, hosting, artifact (an observed hash that differs).
- `passportStep.ts`: `PassportGapDetails`, `PASSPORT_GAP_TEXT` as one function per gap, `whoToAsk`, `alternativesFor` and `MAX_ALTERNATIVES` (5); self-signed authorizations are left out (D-20).
- `routing.ts`: `RouteFacts.observedArtifact` and `candidates`, `RoutePolicy.contact`; the floor reaches the policy steps so each alternative is decided exactly as the request was.
- `placeWords.ts` (new leaf): the place and date words both the trust line and the refusals use.
- `routePolicyFor` sets `contact` from `onboarding.contacts`; `routeFactsFor` takes `catalog`; `nearAiClient.ts` passes `catalog: this.models` on its existing line (1,860 lines kept).

## Deviations from Plan

**1. [Rule 1 - Bug] Load-time cycle** found by gateTrustFacts during Task 1: fixed by `placeWords.ts` (see decisions). Commit ed955c13.
**2. Copy lint:** "risk acceptance" is a glossary word with user word "exception"; the sentences use "exception". Commit ed955c13.
**3. Task 3** needed no production change: `loop.ts` already ends a run on a refused primary and moves past a refused fallback only because the gate refused it before sending. "The primary's model choice in settings is unchanged" is not asserted separately: the loop writes no setting, and the test asserts the run did not switch itself.
**4.** My 74.1-02 tests compared refusals with the old fixed sentences; they now check each gap's own words.
