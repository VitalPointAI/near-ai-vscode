# Phase 74.1 Plan 15: The AI bill of materials Summary

Any open project can export the list of models that worked on it: "Export AI Bill of Materials" (category SovAI, shown only with a folder open) reads this computer's model-request log for the project and writes `.near-ai/state/ai-bom.cdx.json`, a CycloneDX 1.6 bill with one machine-learning-model component per model used: supplier, licence, artifact hash when known, pedigree (the base and each teacher with origin), and properties for origin, approval id and hash, place class, uses served, lane and first and last use. It holds no prompt or answer text, validates against the official CycloneDX 1.6 schema, and a second export of the same log gives the same bytes. The message says it covers the requests this computer still keeps (P11); a `.near-ai/state` that resolves outside the project is refused (P12).
