# Phase 74.1 Plan 07: The research workspace Summary

"Open Research Workspace" (category SovAI) opens one panel with the banner "Research workspace. Adversary models allowed. No project data." Every message runs in a session route whose use is the research lane (research only), carries no tools and no project text, and its record says `lane: t0`. A file from an open project is refused with the lane notice, even when dropped (Q2); any other file is copied into the workspace's own folder in global storage first. Copy puts "From the research workspace, model {model}, untrusted" first, once.
