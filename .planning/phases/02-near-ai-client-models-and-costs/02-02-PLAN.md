# Plan 02-02: Usage, Cost, and Provider Metadata Completion

**Objective:** Complete the NEAR AI provider boundary so chat, analytics, and status surfaces can report trustworthy request identity, usage, estimated cost, actual cost, latency, and verification state.

**Requirements:** MODEL-01, COST-01, PRIV-01, TEST-01

## Tasks

- Normalize provider request IDs, usage headers, pricing fields, and verification/TEE headers into `UsageMetadata`.
- Calculate estimated input/output cost from the selected model catalog and token usage without exposing credentials.
- Add an explicit provider reconciliation boundary for actual usage/cost responses and preserve estimated-vs-actual distinction.
- Add bounded retry/backoff classification for transient provider failures and ensure cancellation stops retries.
- Add unit coverage for metadata normalization, cost calculation, reconciliation, cancellation, and redacted errors.

## Verification

- A completed stream reports request ID, latency, token usage, estimated cost, and verification state when the provider supplies them.
- Actual cost is never presented as estimated cost, and unavailable values remain explicit rather than fabricated.
- Authentication, malformed request, policy, and cancellation errors are not retried.
