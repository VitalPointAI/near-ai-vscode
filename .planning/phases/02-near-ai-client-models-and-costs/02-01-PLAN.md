# Plan 02-01: NEAR AI Client and Model Catalog

## Objective

Create a typed, testable NEAR AI Cloud boundary for authentication, model discovery, pricing, streaming chat completions, cancellation, and request metadata.

## Requirements covered

MODEL-01, CHAT-01, COST-01, PRIV-01, TEST-01

## Tasks

- Implement the OpenAI-compatible HTTP client using the configured base URL and bearer credential without logging secrets.
- Add model catalog and pricing discovery with normalized model metadata.
- Add streaming chat completions through an async event stream with cancellation support.
- Normalize usage, request IDs, latency, estimated cost, and provider/verification headers into a stable response metadata shape.
- Add retry classification for transient failures without retrying authentication, policy, or malformed-request errors.
- Unit test request construction, redaction, model normalization, streaming events, cancellation, and failure classification with mocked fetch.

## Verification

- No secret appears in request errors or structured activity events.
- Model and pricing data can be consumed without depending on raw provider response shapes.
- Streaming emits ordered text/status events and terminates cleanly on cancellation or provider failure.
