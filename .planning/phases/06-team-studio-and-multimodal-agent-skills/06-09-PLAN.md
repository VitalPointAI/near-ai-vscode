<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| webview approval response → host | The browser returns an untrusted fingerprint and operation payload. |
| host approval registry → graph memory | A temporary authorization crosses into a mutating or exporting service. |
| graph export → filesystem/provider | Bounded memory metadata may leave the host only after exact policy approval. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-45 | Spoofing | memory approval fingerprint | critical | mitigate | Compare against a host-created canonical descriptor, not a regular-expression shape check. |
| T-06-46 | Elevation of privilege | chat memory handlers | critical | mitigate | Consume a one-shot exact preview before every mutation and export; never trust webview approval fields. |
| T-06-47 | Tampering | graph version and operation scope | high | mitigate | Bind graph version, scope, IDs, summary/source set, boundary, and session/project to the fingerprint and recheck before commit. |
| T-06-48 | Information disclosure | memory approval/audit DTOs | critical | mitigate | Expose bounded redacted operation metadata and never serialize raw graph content, credentials, paths, or approval authority. |
| T-06-49 | Repudiation | memory approval audit | high | mitigate | Record approval creation, mismatch, expiry, consumption, operation, scope, graph version, and outcome with bounded IDs. |
| T-06-50 | Denial of service | pending approval registry | medium | mitigate | Bound pending entries, TTL, descriptor sizes, and one-shot cleanup; reject malformed requests before allocation. |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installation is planned; any discovered dependency need requires a package-legitimacy review before installation. |
</threat_model>
