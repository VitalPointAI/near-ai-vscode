<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent/provider -> memory graph | Agent-authored claims and provider-derived facts are untrusted evidence and must not become unrestricted authority. |
| webview -> graph host service | Untrusted graph IDs, scopes, filters, edits, exports, and reset requests enter privileged persistence. |
| private/team/project graph scopes | Separate memory namespaces must not leak across agent, team, project, or shared boundaries. |
| graph slice -> prompt/provider | A bounded slice may cross the provider boundary only after privacy, local-only, capability, approval, and budget checks. |
| graph store -> analytics/export | Memory observability and exports expose bounded provenance and operational metadata, never secrets or raw private context. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-23 | Information disclosure | private/team/project graph scopes | critical | mitigate | separate storage namespaces, exact scope checks, opaque IDs, local-only enforcement, and redacted DTO serialization |
| T-06-24 | Elevation of privilege | fact/edge/function capability mutation | critical | mitigate | allowlisted node/edge types, bounded capabilities, provenance transitions, exact-scope authorization, and no agent-authored permission grants |
| T-06-25 | Tampering | correction/merge/retract/reset operations | high | mitigate | expected-version checks, immutable audit history, conflict retention, retraction tombstones, and atomic commits |
| T-06-26 | Spoofing | provenance/confidence/author identity | high | mitigate | host-derived author IDs, source fingerprints, explicit evidence kinds, bounded confidence, and no trusted claims from imported labels alone |
| T-06-27 | Denial of service | graph growth and task slicing | high | mitigate | node/edge/serialized-size limits, decay, bounded traversal, cancellation, emergency stop, and malformed-record rejection |
| T-06-28 | Repudiation | memory retrieval and export | medium | mitigate | bounded audit events recording scope, fact IDs, slice IDs, policy/approval fingerprints, and user mutation outcomes without content |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | no new package-manager dependency; if implementation discovers an install is required, stop for package legitimacy review and a blocking human verification gate |
</threat_model>
