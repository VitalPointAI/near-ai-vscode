<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| webview → chatBridge | Browser-controlled messages request lifecycle or invocation actions. |
| chat host → team/global storage | Host resolves stable IDs and persists global team state. |
| project binding → AgentOrchestrator | A selected immutable version becomes executable routing authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-34 | Tampering | chatBridge team parser | critical | mitigate | Allow only discriminated, bounded lifecycle/invoke fields and reject extra authoritative fields. |
| T-06-35 | Elevation of privilege | chat team-invoke handler | critical | mitigate | Resolve project, provider, capability, policy, and binding facts in the host before AgentOrchestrator.deploy. |
| T-06-36 | Spoofing | selected team version | high | mitigate | Re-read the exact TeamStudioStore version and compare it with the persisted project binding before invocation. |
| T-06-37 | Information disclosure | team preview/status UI | high | mitigate | Send metadata-only DTOs; redact credentials, prompts, raw context, commands, and unrestricted paths in protocol tests. |
| T-06-38 | Denial of service | lifecycle mutation handlers | medium | mitigate | Reuse store bounds, serialize mutations, cap form/package payloads, and return safe errors without repeated work. |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installation is planned; any discovered dependency need requires a package-legitimacy review before installation. |
</threat_model>
