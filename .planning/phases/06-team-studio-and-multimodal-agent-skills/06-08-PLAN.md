<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local file picker → intake | A selected workspace path and file bytes cross into host staging. |
| webview → multimodal host lifecycle | Operation IDs and approvals arrive from an untrusted UI. |
| host → provider adapter | Approved source references and current capability routes cross the provider boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-39 | Tampering | multimodal prepare protocol | critical | mitigate | Accept only opaque staged IDs and allowlisted operations; derive all route and policy facts in the host. |
| T-06-40 | Elevation of privilege | chat → MultimodalOrchestrator | critical | mitigate | Require the orchestrator's exact approval, current capability route, policy decision, budget, and attribution before execution. |
| T-06-41 | Information disclosure | chat status/history/analytics | critical | mitigate | Serialize only bounded IDs, lineage, route metadata, reason codes, and cost facts; exclude raw media, paths, prompts, and credentials. |
| T-06-42 | Denial of service | media operation lifecycle | high | mitigate | Bound source/derived records, use AbortSignal and emergency stop, cap polling/execution, and pause safely on restart. |
| T-06-43 | Spoofing | source-to-derived lineage | high | mitigate | Re-fetch and integrity-check host intake records and persist immutable source IDs, hashes, route snapshots, and lineage edges. |
| T-06-44 | Repudiation | multimodal approval and audit | medium | mitigate | Preserve operation IDs, exact approval fingerprints, attribution, lifecycle status, and redacted audit records. |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installation is planned; any discovered dependency need requires a package-legitimacy review before installation. |
</threat_model>
