<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host graph DTO → webview DOM | Host-controlled but untrusted-to-render data is displayed in a browser context. |
| webview graph action → host | UI controls send scoped IDs, bounded edits, and approval fingerprints back to the host. |
| graph export → user download | A bounded export is exposed only after exact approval and policy checks. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-51 | Information disclosure | graph/table DTO renderer | critical | mitigate | Render only allowlisted metadata and textContent-safe fields; exclude raw private context, media, paths, and credentials. |
| T-06-52 | Tampering | graph action controls | high | mitigate | Use host-derived scope/node/version descriptors and exact approval previews for every mutation/export. |
| T-06-53 | Elevation of privilege | scope filters and action handlers | critical | mitigate | Preserve server-side scope authorization and reject UI attempts to widen scope or supply provider/path authority. |
| T-06-54 | Spoofing | graph node/edge identity | high | mitigate | Use stable host DTO IDs, typed relationship metadata, and refresh after optimistic-version changes. |
| T-06-55 | Denial of service | graph rendering and export | medium | mitigate | Cap rendered nodes/edges/details, retain bounded table/outline data, and avoid unbounded DOM or download payloads. |
| T-06-56 | Repudiation | memory UI actions | medium | mitigate | Announce and audit operation, scope, graph version, approval outcome, and safe error states without raw content. |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installation is planned; any discovered dependency need requires a package-legitimacy review before installation. |
</threat_model>
