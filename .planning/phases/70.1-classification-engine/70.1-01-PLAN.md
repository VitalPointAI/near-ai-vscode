<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| signed policy to the engine | the security officer's section decides thresholds and markings |
| content to the engine | text written by people, agents or outsiders is untrusted data |
| engine to the decision log | records leave the item's label boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-70.1-01 | Tampering | text saying "unclassified" lowering a label | high | mitigate | applied built only with raiseMark from a non-empty start; contradicting banner test (Task 1) |
| T-70.1-02 | Information disclosure | rationale or fact values written to the decision log | high | mitigate | recordForLog keeps hashes only; test (Task 2) |
| T-70.1-03 | Elevation of privilege | a person attribute slipping into the record | high | mitigate | closed key set; person-attribute keys refused by name (Task 2; D-03) |
| T-70.1-04 | Tampering | a policy-supplied regular expression causing catastrophic backtracking | medium | mitigate | marking patterns are literal tokens, never compiled as regular expressions (Task 1) |
| T-70.1-05 | Repudiation | a raise with no nameable event | medium | mitigate | five ids named before shipping and accepted by the record id test (Task 1) |
| T-70.1-SC | Tampering | npm installs | high | mitigate | No package is installed in this plan |
</threat_model>
