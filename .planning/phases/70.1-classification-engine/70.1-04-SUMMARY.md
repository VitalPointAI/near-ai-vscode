# Phase 70.1 Plan 04: assess(), hidden instructions and the red-team set Summary

One pure `assess()` turns content into a decision, a proposal record v1, the events to record and the session's new fact set, with or without a model. A fixed English and French phrase list finds instructions hidden from the reader and aimed at the classifier, which raise `no-agent-tools` and go to review. 29 model-free red-team cases and a 2,000-case property show no text, visible or hidden, lowers a label or suppresses a floor.

## assess() for 74.3

```ts
interface AssessInput {
  start: Mark; current: { item, contentHash, revision };
  visible: string; hidden?: string[];            // the caller extracts hidden parts (comments, zero-width text, alt text, metadata)
  facts?: Fact[];                                // the caller's own scanners' facts (type, opaque subject)
  sessionFacts?: SessionFact[];                  // the session's set before this item
  section; scales; mappings?; modes?; history?;  // as decide()
  judgement?: Judgement;                         // as decide(); requires prompt, rationale and agent
  bundleHash: string;
  prompt?: { templateHash, decodingHash };
  rationale?: { label, text };                   // kept in the record, with the item; the log copy keeps its hash
  agent?: string;                                // the agent's did:key
  noModel?: NoModelCause;                        // with no judgement; 'rules-only' by default
}
type AssessResult =
  | { ok: false; refusal: DecideRefusal | 'bad-fact' | 'judgement-without-context'; message }
  | { ok: true; decision: Decision; record: ProposalRecord; events: LabelEventDescriptor[]; sessionFacts: SessionFact[] };
```

Order: markings and code words over the visible text and every hidden part; the hidden-instruction detector over the hidden parts; guide and compilation rules over the item's facts (the caller's, the judgement's and the hidden-instruction facts); compilation rules over the session set with the item's facts added; `decide()`; then the `hidden-instruction` and `aggregate-cap` exceptions with their `label.exception-queued` events.

## Deviations from Plan

1. **[Owner shape] Portion markings** are written as bare tokens (`S`, `PB`), because the owner-confirmed pattern grammar holds no parentheses. `S` matches any standalone capital S, so it can over-raise (the safe direction). Gap G463.
2. **The plan's hidden-instruction test proposed "Public" on a Protected B start.** Public is on another scale, so the case uses Protected A to test the lowering. The level stays, there is a could-be-lower suggestion, and adding `no-agent-tools` makes the outcome `auto-raised` (a handling raise).
3. **`mark as` was left out of the phrase list:** it flags ordinary comments such as "mark as done". `mark this document` and `mark this as` remain.
