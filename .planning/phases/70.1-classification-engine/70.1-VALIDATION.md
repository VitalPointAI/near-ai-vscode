# Phase 70.1: Validation Strategy

> Per-phase validation contract for 5 plans in 4 waves. Pure code; every test uses fictional content (Example Organization, Exercise NORTHERN EXAMPLE, 1 Example Brigade) and no model or network.

`nyquist_compliant` stays false: every task has an automated check written first, but 70.1-01 and 70.1-05 end in owner checkpoints, 70.1-05's full suite takes longer than the per-task target, and each test file is created by its own task (tests first) rather than in a separate wave 0.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `node:test` through `scripts/run-tests.mjs` (root) |
| **Quick run** | `flock "$HEAVY_LOCK" systemd-run --user --scope -q -p MemoryMax=4G -p MemorySwapMax=0 choom -n 1000 -- timeout 300 env NODE_OPTIONS=--max-old-space-size=1536 sh -c 'npm run compile && node scripts/run-tests.mjs dist/test/<file>.test.js'` |
| **Full suite** | 70.1-05 only, once: first `gateBundleV2.test` and `gateLayers.test` on the branch brought up to date with main, plus the `FEATURE_IDS` check (Task 1); then root `npm run lint && npm test` (6G, 1800 s) with `NEAR_AI_BASELINE_TIGHT=1`, `node scripts/resource-check.mjs` and `node scripts/build-road-to-production.mjs --check` (Task 2) |
| **Estimated runtime** | each root file under 60 s; property files under 90 s |

Never bare `node --test` and never an uncapped `npm test`.

---

## Sampling Rate

- **After every task commit:** the task's own `<automated>` command.
- **After every wave:** every new test file of the wave, `architecture.test.js`, `copyLint.test.js`, `gateRecordIds.test.js`.
- **Blocking in every wave that touches them (data integrity):** the asymmetric property tests (`classifyProperties.test.js`), the red-team cases, the tighten-only layer tests, the record's closed key set.
- **Before `/gsd-verify-work`:** 70.1-05's full suite green once.
- **Browser checks:** none; nothing user-facing ships.
