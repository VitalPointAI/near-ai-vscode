# Phase 70.1 Plan 02: The asymmetric rule Summary

`decide()` is complete: floors apply with certainty in every mode, a model judgement raises only the level through the exact bands of its signed threshold where the level is enforced, every other part of a judgement and every lowering part is a suggestion, large raises go to review, stale judgements change nothing, and anything above the system-high is a possible spill. Five seeded property tests (2,000 cases each) hold the rule.

## Final shapes for 70.1-04 and 74.3

```ts
interface Judgement {
  contentHash: string;                       // must equal current.contentHash, else outcome 'stale'
  proposal: readonly Label[];                // the model's label per scale
  probabilities: Record<'scale/level', bp>;  // calibrated, cumulative, whole basis points 0..10000
  calibration: string; sampleAgreement: bp; secondFamilyAgreement?: bp;
  facts: readonly Fact[];                    // types and opaque subjects only
  rationaleHash: string;                     // SHA-256 of the labelled rationale; the text never enters decide
  model: ModelRef;                           // record v1's model block
}
interface DecideInput {
  start: Mark; current: { item, contentHash, revision }; floors: readonly Floor[]; judgement?: Judgement;
  section: ClassificationSection; scales: ScaleTable; mappings?: readonly ScaleMapping[];
  modes?: Record<'scale/level', 'shadow' | 'enforce'>;          // a caller hold; only ever keeps a level in shadow
  history?: Record<'scale/level', readonly ('pass' | 'fail')[]>; // blind-audit windows, oldest first
}
type DecideResult = { ok: false; refusal: 'no-start' | 'unknown-label' | 'bad-probability'; message } | Decision;
interface Decision {
  ok: true; current; outcome: 'auto-raised' | 'suggested' | 'kept' | 'none' | 'stale' | 'possible-spill';
  start: Mark; applied: Mark; proposal: ProposalPart[]; bases: Basis[]; suggestions: Suggestion[];
  exceptions: { kind: 'large-raise' | 'possible-spill' }[]; confidence: Confidence | null;
  notify: boolean; freeze: boolean; events: LabelEventDescriptor[];
}
interface LabelEventDescriptor {
  event: 'label.auto-raised' | 'label.exception-queued' | 'label.could-be-lower';
  from: Mark; to: Mark; bases: Basis[]; exception?: ExceptionKind; suggestions?: Suggestion[];
}
```

Outcome order: `possible-spill`, then `auto-raised` (applied rose), `suggested` (a raising suggestion: band, shadow, judgement-only, no-threshold), `kept` (a floor or judgement found nothing above start; lowering suggestions only), `none` (no floor and no judgement). `withinSystemHigh(label, section, scales, mappings)` uses dominance's own mapping rule (`whyNotDominated`, scale and level only).
