# Plan 26-01: Measurement

1. Activity store: replace the 100-event cap with a byte bound and a 5 000 ceiling (write and load); keep every existing bound on sessions.
2. Record `cachedInputTokens` on model events, `tool` and `durationMs` on tool-end events, and add `cachedInputTokens`, `approvalTimeouts` to SessionCounters; add a `run` split (wall, model, tool, approval, idle, tokens) written when the main agent ends.
3. `src/services/runReport.ts`: a pure report over a ledger; `scripts/run-report.mjs` and `npm run report:runs`; the `nearAi.showRunReport` command opens it as Markdown.
4. Tests: store bound, split recording, report on a fixture ledger (approval timeouts, percentiles, cache rate).
