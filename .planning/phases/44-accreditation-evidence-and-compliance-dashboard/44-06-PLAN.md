Planning choices (reported):
1. `sources.json` is written only by the import command (registry facts plus retrieval date and hashes), so the code PR never carries it and the data PR owns it (D-42, pitfall 3). The registry of what each source is and its licence evidence lives in `sourceRegistry.ts`.
2. Commands are files under `src/commands/` and importers files under `src/import/`, loaded by name, so later plans add commands without editing the dispatcher.
3. The Open Government Licence attribution statement is written with a hyphen ("Open Government Licence - Canada"), as CONTEXT D-03 writes it, to keep the no-em-dash rule.

This plan has a blocking human checkpoint (Task 2) for the two importer packages, as D-44 requires. Task 1 runs before it, so the owner is asked as early as possible.

Branch `feat/phase-44-06-importer-foundation` (D-39).

## Artifacts this phase produces

Phase-wide surface: see 44-01 "Artifacts this phase produces".

This plan creates:
- CLI `node compliance/src/cli.ts <command>` (and `npm --prefix compliance run cli -- <command>`): names `^[a-z][a-z0-9-]*$` resolve to `compliance/src/commands/<name>.ts`, each exporting `run(argv): Promise<number>`; an unknown name prints the list and exits 2.
- Command `import <source> [--out-root <dir>] [--lang en|fr|both] [--offline <dir>]`: resolves `compliance/src/import/<source>.ts` exporting `importSource(context): Promise<ImportResult>`; `--offline` reads pages from `<dir>/pages.json` (url to file) instead of the network; writes under `--out-root` (default `compliance/`).
- Command `licence-check [--out <file>]`: exit 0 when every record still says its recorded licence, exit 3 when any differs or cannot be read.
- Command `watch [--out <file>]`: one JSON report { checkedAt, sources[] { id, url, result changed, unchanged, moved or failed, sha256?, previous? } } and a Markdown summary on stdout; exit 0 whenever it ran, 2 only when it could not run at all.
- `compliance/src/import/lib/sourceRegistry.ts`: `SOURCE_REGISTRY`, `SourceEntry` { id, title, publisher, pages[] { url, lang? }, licence (ca-ogl-lgo, us-public-domain, us-government-work, reproduction-of-federal-law-order, canada-ca-terms, all-rights-reserved, mit-0, cross-check-only), licenceEvidence { kind ckan, recordId } or { kind page, url }, use (text, ids-and-links, cite, cross-check), browserAgent? }.
- `licence.ts`: `ALLOWED_TEXT_LICENCES`, `mayStoreText(entry)`, `checkCatalogTextLicence(catalog, registry)`; `fetch.ts`: `ALLOWED_HOSTS`, `createFetcher({ fetchImpl, sleep, now })` with `get(url, { maxBytes, accept })`; `write.ts`: `writeImportResult(outRoot, result, registry)`; `notice.ts`: `buildNotice(sources)`; `cyberHtml.ts`: `parseHtml`, `mainOf`, `controlSections`, `subSections`, `listItems`, `parseParameters`, `normalizeId`, `labelOf`, `nistIdOf`; `normalize.ts`: `normalizedMain(html)`, `normalizedHash(html)`; `oscalBuild.ts`: `newCatalog({ sourceId, title, version, retrievedAt })`, `newGroup`, `newControl({ id, title, label, class, props })`, `statementPart(items)`, `proseWithParams(text, controlId)` (replaces each parameter with an OSCAL insert and returns its `params`), `newProfile`, `newMapping`, all stamping `oscal-version` 1.2.1, sorting keys and using the `NS` props, shared by every wave 3 importer.
- `compliance/schemas/sources.schema.json` ({ sources[] { id, title, publisher, licence, licenceEvidence, use, pages[] { url, lang?, sha256?, bytes?, dateModified? }, retrievedAt?, licenceCheckedAt? } }).
- devDependencies `parse5` 7.3.0 and `yaml` 2.9.1 (exact, after the checkpoint).
