## Artifacts this phase produces

Phase-wide surface: see 44-01 "Artifacts this phase produces".

This plan creates (each a `Collector` from 44-01's types; 44-14 lists them in the bundle; `repository` comes in the input as `owner/name`):
- `audit.ts`: `auditCollector` (input { audits: [{ package, file }] }, window audit; observation `audit` / `<package>` passed when high plus critical is 0; counts per severity from the npm audit JSON `metadata.vulnerabilities`).
- `sbom.ts`: `sbomCollector` (input { sboms: [{ subject, file }], scans: [{ subject, file }] }, window head; `sbom` / `vsix` and `sbom` / `relay-image` passed when the CycloneDX file parses with at least one component, counts components, hash the file's SHA-256; `image-scan` / `relay-image` passed when no match is high or critical, counts per severity).
- `release.ts`: `releaseCollector` (input { repository, tag }, window attestation; `release` / `<tag>` passed when the tag's commit is on main and the release's checksum asset equals the VSIX's SHA-256; counts assets).
- `attestations.ts`: `attestationsCollector` (input { repository, subjects: [{ name, sha256 }] }, window attestation; `attestation` / `<name>` passed when at least one provenance attestation exists for that digest).
- `settings.ts`: `settingsCollector` (input { repository }, needs the read-only settings token, window settings), `SETTINGS_CHECKS`: required-checks, docs-required, enforce-admins, review-required, tag-ruleset, environment-marketplace, environment-agent-review-gates, codeowners-valid, each an observation `settings` / `<check>`.
- `reviews.ts`: `reviewsCollector` (input { repository, since }, window settings; `review-trail` / `agent-review`, `review-trail` / `gate-approvals`, `review-trail` / `publish-approvals`, counts prs and missing, and the PR numbers missing evidence).
- `codeScanning.ts`: `codeScanningCollector` (input { repository }, window head; `code-scanning` / `codeql` passed when the newest analysis is for the head commit and no open alert is high or critical; counts per severity).
- `github.ts`: `githubList(fetchJson, path, params)` following pages of 100 until a short page.
