## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| third-party actions and tools to CI | code that runs with the job's token |
| pull request code to CI | untrusted code runs in the compliance job |
| release job to the attestation service | id-token write mints signed provenance |
| reporting jobs to the merge and tag gates | any failed check blocks merge-pr and tag-release |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-44-65 | Tampering | actions and tools | high | mitigate | every action pinned by SHA, tools by SHA-256 through install-tool.sh, no marketplace scanner actions; tested (Tasks 1 to 3) |
| T-44-66 | Elevation of privilege | id-token write | high | mitigate | only in `attest`, which checks both checksums first and runs no npm or checkout; tested (Task 3) |
