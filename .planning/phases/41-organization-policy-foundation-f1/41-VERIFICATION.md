### Warnings (not blocking)

**W1. README and CHANGELOG overstate the export-control default for upgraded installs.** Both say content marked CGP, ITAR or EAR "stays on this computer under the starting rules". The code (D-62, bundleStore `tryRenew`) adds the compartment entries only on a fresh install or when unedited starting rules are renewed, which happens in the last 30 days of a 365-day policy. An install that upgrades with unedited pre-Phase-41 starting rules keeps routing those markings by level until renewal, up to about 11 months. SECURITY.md ("Export-controlled content") says this correctly; README line ~1480 and the CHANGELOG "Export-controlled content stays here by default" bullet do not. Suggested fix: add SECURITY.md's sentence "A fresh install, and the renewal of starting rules nobody edited, get these entries" to both, or (code option) renew unedited pre-Phase-41 starting rules at load.
