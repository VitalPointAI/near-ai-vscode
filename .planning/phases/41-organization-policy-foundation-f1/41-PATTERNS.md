## Conventions (from the code on main)

**Parsing.** `Parsed<T> = { ok: true; value: T } | Refusal` and `refused(reason, path)` from `src/domain/gate/shape.ts`. Reasons come only from `GATE_SHAPE_FAILURES` (`unknown-field`, `missing-field`, `wrong-type`, `empty-list`, `unknown-version`, `not-available-yet`, `not-sorted`, `duplicate`, `not-allowed-here`, `unknown-verb`). Paths built with `childPath`; list items as `` `${path}[${index}]` ``; `safePath` cuts untrusted keys to 40 characters. Read fields with `ownValue`, check with `isRecord` (plain objects only), exact keys with `checkKeys(value, path, required, optional)`. Times only in `YYYY-MM-DDTHH:MM:SS.sssZ` (`parseIsoMillis`). Numbers only non-negative safe integers (`checkNumbers` in `bundle.ts`). Freeze outputs.

**Refusal objects and failure texts.** A failure set is a `const` record of plain sentences keyed by reason (`BUNDLE_FAILURES`, `PAYLOAD_FAILURES`, `INVITE_REFUSALS`, `ROUTE_REFUSALS`, `BINDING_REFUSALS`); the type is `keyof typeof`; "a reason is added here with its sentence and a test, never at a call site" (`bundle.ts` 565-569). A route refusal starts "Nothing was sent." and ends with what to do. Store-level failures throw a named error class with a message that starts "Nothing was changed:" or "Nothing was written:" (`BundleStoreError` in `bundleStore.ts:53-58`). No em-dash in any sentence; tests assert it.

**Failed closed.** A state the code cannot read is a refusal, never a guess (`routeCheckFailed`, `failedClosed`, `bundleStateOf` in `sessionMark.ts`). Load paths never throw (`GateHost.start`, `loadPolicyBundle`).

**Rule ids and events.** Lowercase dotted ids (`route.local-only`, `policy.edit`, `label.set`); route rules in `ROUTE_RULES`, policy events in `POLICY_EVENT_IDS`, label events in `LABEL_EVENT_IDS`; all flow into `RECORD_RULE_IDS` (`decide.ts:186`). Name every id the phase will write in the first plan that ships (D-49). Route records go to the model-request log because `MODEL_REQUEST_RULES` includes `ROUTE_RULES` (`record.ts:351`).

**Signed purposes.** Append to `PAYLOAD_PURPOSES` with a comment naming the phase and decision; add a sample and update the exact list in `src/test/teamSignedPayload.test.ts`; add `GENERATED_PATHS` only for fields that hold random bytes; prefer field names `publicKey` and `sig` for key and signature material (the only names the secret scanner exempts).

**Key sources.** Each verification names its own `KeyStatusLookup`; never combine a team's or organization's source into a personal check, or the reverse (`keyStatus.ts` header).

**Hostile files.** Size cap before `JSON.parse`, own properties only, never spread parsed input into a trusted object, a file extension constant, a closed refusal record (`invite.ts` header 16-17).

**Layer imports.** `src/domain/**` imports only `src/domain/**` and `node:crypto` (and no package); `src/gate/**` imports `src/gate`, `src/domain`, `src/team`, the type-only `services/auth` and `services/stateMirrorLock`; editor code is `src/services/**`. `teamBoundaries.test.ts` enforces the gate folders today; add a `domain/org` and `domain/provider` rule there or in the new architecture test.

**Test files.** `src/test/<area><Thing>.test.ts` in camelCase (`gateBundleV2.test.ts`, `gateEndpoints.test.ts`, `orgModes.test.ts`); `import test from 'node:test'` and `import assert from 'node:assert/strict'`; titles are plain sentences saying what holds, with decision ids in the title where one applies ("D-49: ..."); a "has teeth" test for every scanner; cross-process tests use a child helper in `src/test/helpers/` (`gateBundleChild.ts`). Run one file with `systemd-run --user --scope -q -p MemoryMax=4G -p MemorySwapMax=0 choom -n 1000 -- timeout 300 env NODE_OPTIONS=--max-old-space-size=1536 sh -c 'npm run compile && node scripts/run-tests.mjs dist/test/<file>.test.js'`.

**Header comments.** Each source file opens with what it is, its requirement and decision ids, and its purity ("Pure: no I/O, no clock, no vscode, no package."). New decision ids for Phase 41 should continue the numbering in its CONTEXT file.

**Copy.** "your organization"; "NEAR AI"; "VS Code"; "self-signed on this computer" until an issuer exists; scale name with level ("Canada, Protected: Protected B"); panel titles without a brand prefix; no "tier", "TEE", "Team Mode" or "profile" on new screens.
