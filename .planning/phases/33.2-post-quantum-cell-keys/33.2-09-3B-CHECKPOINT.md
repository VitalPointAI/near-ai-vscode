### 3B.2b2 storage contract

The current `SecretStorageLike` interface can return the protected bytes after a write. It supplies neither a deadline-conditional write nor a receipt binding the instant the write became durable. The effective clock in `bundle.ts` can supply an expiry check. The locks can order cooperative authority changes. Neither connects the clock to the asynchronous file or protected-state commit. Reading exact bytes on restart can establish which candidate survived, while the before-deadline outcome remains unresolved. An early clock sample or a second ordinary protected write leaves the same uncertainty when the process stops before acknowledging its result.

Before selection can proceed, review a primitive that enforces the deadline at commitment and can recover an authenticated decision for the exact attempt, protected capture, snapshot, root and bytes after loss of the response. A valid decision would still require fresh authority for each use. Keep absent, pending and ambiguous decisions unselectable. No current interface in this path supplies that primitive. This is a design dependency for a separate review.
