```javascript
// welcomeState(value): value is the profile-status value { noWorkspace?, profiles, activeProfileId, ... }
```

```javascript
welcomeState(value)          // identical to PR #7, case for case

track(win, doc)              // installed automatically in the page: on each profile-status message, sets doc.body.dataset.profile to the state and calls listeners
current()                    // the last state, or undefined before the first profile-status (treated as not ready)
onChange(listener)           // listener(state); returns a function that removes it
```
