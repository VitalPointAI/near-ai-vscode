<objective>
Build the cryptography that lets a lead hand a member their NEAR API key without the key ever existing in clear text outside the two devices: an X25519 key per device kept in SecretStorage, sealing and opening with ECDH, HKDF-SHA256 and AES-256-GCM bound to team, member, device and key id, and secret-detector exemptions that accept only the exact sealed shapes. The tracer seals a key to a device whose private key is loaded back from SecretStorage and opens it again.

Purpose: D-23 (key sealed to one device), which makes D-21's lead-created key deliverable; criterion 4 (no clear-text key anywhere).
Output: src/team/keySeal.ts, seal identity in src/team/identity.ts, exemptions in src/domain/team/secrets.ts, tests.
</objective>
