<objective>
Build the three export formats and the per-run diff — SARIF 2.1.0 with verdict-mapped levels and embedded authorization, JSON, and the fully populated PTES Markdown report, each carrying the disclaimer block and the missing-tools note — the added/resolved/unchanged finding diff between runs of the same engagement, and the deterministic visual capture that populates the Evidence Appendix (D-27 evidence kind 4).

Purpose: CYBER-12 is the phase's delivery surface — the report and evidence are the product, not a by-product (CONTEXT.md specifics). Success criterion 5's transcript replay and criterion 4's audit trail both land on these files, and D-27's fourth evidence kind lands on the appendix this plan owns.
Output: src/services/cyberSarifExport.ts, the extended src/services/cyberReport.ts, src/services/cyberVisualCapture.ts, two test files.

Recorded planning choices:
- SARIF validation is structural (hand-rolled assertions over the exported object per the research's Required Fields analysis: version, runs[].tool.driver, results[].message.text, locations presence) — no ajv/json-schema dependency, consistent with the zero-new-dependency decision.
- The diff is computed over stable finding ids (finding id = engagement + check id + target), not array positions.
- **Visual capture form (D-27 kind 4).** True browser screenshots need a host browser (Playwright/Puppeteer, or a `chromium`-style binary), which is a new dependency and a new network surface — both barred by this phase's zero-new-dependency decision. The shipped capture is therefore a *text-artifact visual*: deterministic SVG rendered in-process from stored evidence bytes with `node:` built-ins only. The appendix states the browser requirement plainly instead of pretending the screenshot sub-form exists. This delivers the evidence kind rather than superseding it: a visual artifact is produced, hash-linked, and referenced from the Markdown report exactly as D-27 asks; the only named gap is the browser-backed screenshot, and it is recorded absent-with-reason in the appendix itself, matching D-12's never-silent register.
- Rendering is pure string assembly over evidence-derived values, so `node --test` owns the determinism proof; no SVG library and no canvas.
</objective>
