## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Target -> extension host | Probe responses are untrusted input (headers, bodies, banners) crossing into model context |
| Model -> harness | Model-emitted step JSON is untrusted instruction-shaped input validated before execution |
| Extension host -> globalStorage | Persisted engagement/ledger/evidence must resist tampering and secret leakage |
| Harness -> target | Outbound probes must stay inside resolvedScope and the engagement's rate/window limits |
