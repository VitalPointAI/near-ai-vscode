## Local shared-project accessor checkpoint

`StaffHost.sharedReplica()` provides the project half of the Task 3 contract. It reuses the host's lazily opened pinned replica and checks the current signed fold and the device's roster admission. Before handing out the project it compares the store inode and recorded roster head against that verification. A replaced or rolled-back store yields no handle for that attempt. The accessor can retry through the existing host lifecycle on the next call.

The tests exercise reuse, non-shared and unpinned folders, signed device admission loss, rollback followed by recovery, and replacement during the verification fold. `staffHost.ts` stays at 1688 lines. The first API check on the base found no public accessor.
