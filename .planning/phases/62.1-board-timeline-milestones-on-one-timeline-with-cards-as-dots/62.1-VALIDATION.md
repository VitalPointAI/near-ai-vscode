## Sampling Rate

- **After every task commit:** the task's own `<automated>` command (the touched test files plus their neighbours).
- **After every plan wave:** `node --test dist/test/teamTimeline*.test.js dist/test/boardTimeline*.test.js dist/test/boardClient.test.js dist/test/teamBoardAssets.test.js dist/test/teamPlainLanguage.test.js`.
- **Before `/gsd-verify-work`:** `npm run check`, every e2e launch, both screenshot parts, the browser command and `npm run verify:release`, all green (62.1-09 Task 3).
- **Max feedback latency:** 60 s for unit runs.
- Security and integrity checks block at once when touched: the CSP and message parser tests, the page safety scans, the release content check, the invariants (no vscode import in the team core, nothing signed or stored changed, no dependency added). Never delete, skip or weaken a failing test.
