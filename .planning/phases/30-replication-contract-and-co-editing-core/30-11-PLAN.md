<objective>
Freeze the replica contract as bytes and as an import boundary: canonical vectors other phases and the hub test against (D-28), and a boundary test proving the replica core is pure, that only doc.ts touches Yjs, and that the hub-side modules compile without it (D-01, D-17).

Purpose: Phase 32's hub is built in its own workspace without importing extension code; it needs the exact bytes and a set of modules it can compile alone.
Output: a vectors fixture, its builder and test, and the boundary test.

Runs in wave 4 beside 30-10 (disjoint files): every replica file exists after wave 3, and the vectors need the hardened entry format (30-04), the proof (30-05), the checkpoint (30-09) and the version hash (30-08). The digest vector is added in 30-12 once all reducers are registered.

Recorded planning choices:
- Fixed keys come from labels (seed = sha256 of the label, through `fixedSigner` in `src/test/helpers/replicaWorld.ts`); the fixture stores labels, public keys and outputs, never private key bytes, so the secret scan stays clean. These are test keys and the fixture says so.
- Sealing for vectors uses a test-only sealer with a fixed IV (first 12 bytes of sha256 of a label) through `node:crypto` directly; production `sealRaw` always uses a random IV. Opening in the test uses production `openRaw`, so the vectors prove the production reader.
- The boundary test is its own file (importing `teamBoundaries.test.ts` would register its tests twice); it re-implements the same line-based import scan and adds a transitive check, because the hub must compile the hub-side closure including type-only imports.
</objective>
