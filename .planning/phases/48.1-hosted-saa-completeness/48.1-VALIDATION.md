## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `node:test` through `scripts/run-tests.mjs` (TypeScript by Node type stripping in `compliance/`; `.mjs` in `deploy/` and `scripts/test/`) |
| **Config file** | none; `npm --prefix compliance ci --ignore-scripts` once per checkout; helm from `sh compliance/ci/install-tool.sh helm compliance/out/tools` for deploy tests |
| **Quick run command** | `systemd-run --user --scope -q -p MemoryMax=4G -p MemorySwapMax=0 choom -n 1000 -- timeout 300 node scripts/run-tests.mjs <the one mapped test file>` (deploy tests with `env HELM=compliance/out/tools/linux-amd64/helm`) |
| **Full suite command** | the same wrapper on `npm --prefix compliance test`, then `deploy/test/*.test.mjs` with helm, then `scripts/test/*.test.mjs`; plus `node compliance/src/cli.ts hosted-docs --check`, `node compliance/src/cli.ts validate`, `node scripts/resource-check.mjs` (one heavy run at a time) |
| **Estimated runtime** | ~180 seconds |

---

## Sampling Rate

- **After every task commit:** the single mapped test file with the capped wrapper, and `hosted-docs --check` when a source or document changed
- **After every plan wave:** the full suite once, on the wave's combined branch before its pull request
- **Before `/gsd-verify-work`:** full suite once, a local `bundle` and `package` with the hosted levels, the hosted SSP inspected, `node docs-site/scripts/sync-docs.mjs` for links
- **Max feedback latency:** 300 seconds
