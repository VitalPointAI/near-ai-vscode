# Phase 48.1 Plan 01: Generated hosted documents and the exchange register Summary

One JSON source (`compliance/hosted/exchanges.json`, 15 exchanges) now generates the exchange and interconnection register and its Mermaid diagram inside a hand-written document; the required docs CI job fails on drift or on a deploy module that signs or verifies a file without an exchange; all thirteen hosted SA&A documents are required documents; every 48.1 area has a gap row.

## Block mechanism

New, not the catalogue's (it regenerates whole pages and has no marker form). `hosted-docs --check` compares each block with its source and runs the block's source checks; `--write` rewrites blocks. The documents collector adds `stale-blocks` to the observation of any document with generated blocks and fails it above 0. The command and `compliance/src/hosted/` import only Node built-ins (tested), so the docs job runs it before `npm ci`.
