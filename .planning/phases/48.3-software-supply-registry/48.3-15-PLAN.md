<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pull request head -> CI | a change may add dependencies, alter pins, lists or the code that checks them |
| protected base ref -> CI | the only source of the checker, its pins and the trusted key |
| public registries -> GitHub-hosted runners | approved bytes fetched from public origins until the runner move (G517) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-48.3-64 | Tampering | an unapproved dependency merged | high | mitigate | the required deploy job fails on any entry not in the signed list (or held at its exact integrity) |
| T-48.3-65 | Elevation of privilege | a pull request loosening the checker, its pins or the key | high | mitigate | CI runs only the base ref's copy (D-37 a); the paths are gate paths (D-37 b, 48.3-13); test "loosened head" |
| T-48.3-66 | Tampering | an install script or git dependency running in CI | high | mitigate | workflow-wide `NPM_CONFIG_IGNORE_SCRIPTS` and `NPM_CONFIG_ALLOW_GIT=none`, besides each command's flag |
| T-48.3-67 | Tampering | an older signed list replayed to re-admit a withdrawn version | high | mitigate | serial below the base's is refused; withdrawn entries refused |
| T-48.3-101 | Repudiation | the bootstrap pass reused by another pull request | medium | mitigate | the pass needs this plan's exact branch, this repository and base main, and a trusted ref without the checker, which stops being true once this plan merges; every other case fails (test) |
| T-48.3-104 | Elevation of privilege | a pull request into an unprotected base, or a push to an unprotected branch, choosing its own trusted copy | high | mitigate | the trusted ref falls back to `origin/main` unless the base or ref is main, release/* or a release tag (W1, test) |
| T-48.3-105 | Elevation of privilege | a new dependency held instead of approved | high | mitigate | held entries must already be held in the base list; writeList and the review command refuse new holds after the baseline (B1) |
| T-48.3-SC | Tampering | npm installs | high | mitigate | No package is installed in this plan |
