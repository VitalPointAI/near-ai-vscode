## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `node:test` through `scripts/run-tests.mjs` (`.mjs` in `deploy/test/` and `scripts/test/`; TypeScript by Node type stripping in `compliance/test/`) |
| **Config file** | none; pinned tools from `sh compliance/ci/install-tool.sh <tool> compliance/out/tools` (cosign for the list and attestation checks, helm for renders, syft for the SBOM fixture); podman for the spikes and local image builds; softhsm2-util and pkcs11-tool for spike S-A |
| **Quick run command** | `systemd-run --user --scope -q -p MemoryMax=4G -p MemorySwapMax=0 choom -n 1000 -- timeout 300 env NODE_OPTIONS=--max-old-space-size=1536 node scripts/run-tests.mjs <the one mapped test file>` (render tests with `HELM=compliance/out/tools/linux-amd64/helm`; list checks with `compliance/out/tools` on PATH) |
| **Full suite command** | the same wrapper with 6G and timeout 1800 on `node scripts/run-tests.mjs deploy/test/*.test.mjs` (CI's deploy job), then `scripts/test/*.test.mjs`, then `npm --prefix compliance test`; plus `node scripts/resource-check.mjs`, `node scripts/build-component-catalogue.mjs --check`, `node scripts/build-road-to-production.mjs --check`, `node compliance/src/cli.ts validate`, `node deploy/supply/check-inputs.mjs --root . --public-key deploy/supply/keys/build-hq.pub --base-lists deploy/supply/approved` (from 48.3-15; in CI it runs only from the base ref, D-37); one heavy run at a time |
| **Estimated runtime** | ~300 seconds for the full suite; spikes and local image builds are separate heavy runs |

Where a check blocks: the deploy job (required) runs every `deploy/test/supply-*.test.mjs` and, from the pull request after 48.3-15, the base ref's input check; resource-check in `lint`; the catalogue check in `test`; the road-to-production check in `docs`; the workflow and gate-path tests in `scripts/test/` (gate paths).

## Sampling Rate

- **After every task commit:** the single mapped test file with the capped wrapper; resource-check and the catalogue check when the register changed; the road-to-production check when `gaps.json` changed.
- **After every plan wave:** the full suite once, on the wave's combined branch before its pull request.
- **Before `/gsd-verify-work`:** the full suite once, a local bundle with `--source-registry` against a local registry, `node compliance/src/cli.ts validate`, and the lab run's SUMMARY (48.3-22).
- **Max feedback latency:** 300 seconds.
