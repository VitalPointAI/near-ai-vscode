  <action>
Redactor (`src/log/redact.ts`, D-11, Pitfall 10): `register(name, value)` throws for values shorter than 8 characters and stores the rest; `text(value)` replaces every registered value with `[secret:{name}]`, replaces free text matching a plus sign followed by a digit, 6 to 18 digits or separators (space, dot, hyphen, parentheses) and a final digit with `phone:{8 hex}` (first 8 hex of HMAC-SHA256 over the digits only, keyed by the pseudonym key) or `phone:unlabelled` while no key is set, and truncates to 500 characters ending in `...`. Dates such as 2026-11-14 and bare digit ids have no plus sign and stay unchanged. `fields(input)` normalises each key (lowercase, non-alphanumerics removed); a key in SENSITIVE_KEYS (authorization, proxyauthorization, cookie, setcookie, xapikey, apikey, text, message, body, content, prompt, password, secret, token) is dropped and replaced by `{key}Length` with the string length (or 0); a key whose normalised form contains `phone` is always labelled as a phone; any value that is not a LogValue becomes `[dropped:{typeof}]`; strings go through `text`. `setPseudonymKey(key)` installs the HMAC key.

Logger (`src/log/logger.ts`): `Logger(redactor, sink = line => process.stdout.write(line + newline), now = Date.now)` writes one JSON object per call with `time` (ISO from now()), `level`, `event` (must match lowercase letters, digits, dot, underscore, hyphen; otherwise `invalid-event`) and the redacted fields. This file is the only relay source that writes to stdout.

Wiring (`src/main.ts`, `src/http/server.ts`): create the Redactor (with a per-process random 32-byte pseudonym key from node:crypto until plan 06 installs the D-18 key) and the Logger before anything else in `main`, then add the events listed in artifacts_produced: `relay.start_refused` with `reason` (`config` for a ConfigError or a bad argv, `listen` for a listen error) and `detail` (the error message, which passes through the Redactor and names the variable, never its value), then exit 1; `relay.listening` with host, port and version after listen; `relay.stopping` and `relay.stopped` around shutdown and `relay.stop_timeout` before the hung-shutdown exit; `relay.crashed` with the error name, code and the message as `detail` for an uncaught exception, then exit 1; `relay.healthcheck_failed` with the status or error name when `runHealthcheck` returns 1 (successful healthchecks print nothing). Pass `onRejected` to createRelayServer so 404, 405 and 5xx log `http.rejected` with route label, method and status only; successful /healthz calls are not logged. Update `test/startup.test.ts` to start with RELAY_PORT=0 and read the port from relay.listening (keep its free-port helper for the --healthcheck case), and add the behaviors above (D-11).
