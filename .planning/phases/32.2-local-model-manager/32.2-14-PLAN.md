## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| webview page -> extension host | every message is untrusted |
| host -> webview | text drawn in the page comes partly from servers and catalogues |
| page -> browser | links open outside VS Code |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-32.2-68 | Tampering | forged or malformed page messages | high | mitigate | the kit's typed protocol drops them; the service also checks offered actions (Task 1, 32.2-12) |
| T-32.2-69 | Tampering | HTML or script injection through server or catalogue text | high | mitigate | textContent only, no HTML strings (Task 1 guard, the kit's scan rule) |
| T-32.2-70 | Spoofing | a link to an address the page chose | medium | mitigate | links by id; fixed https addresses or the signed catalogue's https licence URL only (Task 3) |
| T-32.2-71 | Elevation of privilege | a research-only model selectable for a job on screen | high | mitigate | no select in the research list; job selects list only the view's choices (Task 2) |
| T-32.2-72 | Repudiation | an install or removal without the person seeing the licence or the jobs affected | medium | mitigate | licence and remove dialogs drawn from the service's dialog models before any action (Tasks 2 and 3) |
| T-32.2-SC | Tampering | npm installs | high | mitigate | No package is installed in this plan |
</threat_model>
