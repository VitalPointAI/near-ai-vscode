<objective>
D-19 and D-35: OpenSSF Model Signing is verified when an artifact carries a signature and the catalogue names the signer; built and tested with fixtures, optional for the shipped set (none of the target repositories ships a signature today). The catalogue needs a place to name the signer, so the Phase 41 artifact shape gains one optional key in `models.ts` with two narrowing rows in `layers.ts` (D-01: an additive change by the plan that needs it, noted for the integration merge). The signer is named by its public key inside your organization's signed catalogue, which covers both the key method and the certificate method of model signing without shipping any trust root; keyless identities that need the Sigstore root and transparency log verify only if their certificate's key is the pinned one.

Purpose: when your organization signs its model files, the manager checks that signature too, on top of each file's hash.
Output: one pure verifier, two shared gate files edited, two existing tests extended, one test helper, one new test. Branch `feat/phase-32.2-09-signing`.
</objective>
