## Pattern Assignments

### Pure domain files under `src/domain/localModels/` (plans 01, 02, 03, 04, 05, 09, 11, 12)

**Analog:** `src/domain/gate/shippedPassports.ts` (header lines 1-12) and `src/domain/provider/localServer.ts`.

Convention: a leading comment naming the requirement and decision, then "Pure: types only" or "no I/O, no clock, no vscode". Import types only from sibling domain files.
```typescript
// FND-09, D-43: how the editor looks after a local model server. Interface only. ... Pure: types only.
import type { Passport, PassportLegal } from './models';
```
Keep each file under 800 lines (`WARN_ABOVE` in `src/test/helpers/architectureScan.ts:50`). Domain code may import only `src/domain`.

### Shipped catalogue and local passport rows (plan 03)

**Analog:** `src/domain/gate/shippedPassports.ts` lines 52-63, row builder:
```typescript
function nemotron3(size: 'Nano' | 'Super' | 'Ultra'): Passport {
  return row({ id: `nvidia/nemotron-3-${size.toLowerCase()}`, match: [`nvidia/NVIDIA-Nemotron-3-${size}-*`], developer: 'NVIDIA', origin: 'US',
    lineage: { ... }, licence: { id: '...', obligations: ['attribution'], inherited: [...] }, hosting: ['nearai-tee'], maxTier: 'T2' });
}
```
New local rows add hosting class `local` and an exact `artifact` ({ format, sha256, quantization, remoteCode: false }), because `ARTIFACT_REQUIRED_CLASSES` refuses a T2 passport hosting `local` without one (`src/domain/gate/models.ts:59`, `369-373`). A row's id never changes in place. Catalogue types `LocalCatalogueEntry` and `LocalArtifact` are at `models.ts:127-141`; the parser `parseModelsSection` (485-538) needs the passport in the same section, `minFitBand` a token (`/^[a-z0-9][a-z0-9-]{0,31}$/`), 64-hex sha256, positive integer sizes. Plan 09 adds the signer field to the same types.

**Test analog `src/test/gatePassports.test.ts`:**
```typescript
import assert from 'node:assert/strict';
import test from 'node:test';
import { parseModelsSection, passportCovers, resolvePassport } from '../domain/gate/models';
import { SHIPPED_PASSPORTS } from '../domain/gate/shippedPassports';
function digest(label: string): string { return createHash('sha256').update(`gate-passports/${label}`, 'utf8').digest('hex'); }
```
Parse the shipped catalogue as `{ v: 1, passports: SHIPPED_PASSPORTS, localCatalogue }` as `gatePassports.test.ts:389` does.

### Detection, download, disk, ledger (plans 02, 05, 10)

**Analog:** `src/services/emergencyStop.ts`: node built-ins first, then `vscode`; module-level state; atomic work with `writeFileSync` plus `renameSync`.
```typescript

import * as path from 'node:path';
```

Download guard is exactly `isEmergencyStopped()` plus the host allowlist. Partials go under extension storage `downloads/<id>.partial`, then rename after the hash matches. Inject `execFile`, `statfs`, clock and HTTP as seams so tests use fakes from `src/test/helpers/`.
