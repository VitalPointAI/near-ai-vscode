## Pattern Assignments

### Domain files under `src/domain/localModels/` (plans 01, 03, 04)

**Analog:** `src/domain/gate/shippedPassports.ts` (header lines 1-12) and `src/domain/provider/localServer.ts`.

Convention: a leading comment naming the requirement and decision, then "Pure: types only" or "no I/O, no clock, no vscode". Import types only from sibling domain files.
```typescript
// FND-09, D-43: how the editor looks after a local model server. Interface only. ... Pure: types only.
import type { Passport, PassportLegal } from './models';
```
Keep each file under 800 lines (`WARN_ABOVE` in `src/test/helpers/architectureScan.ts:50`). Domain code may import only `src/domain`.

### `shippedCatalogue.ts` and local passport rows (plan 03)

**Analog:** `src/domain/gate/shippedPassports.ts` lines 52-63, row builder pattern:
```typescript
function nemotron3(size: 'Nano' | 'Super' | 'Ultra'): Passport {
  return row({ id: `nvidia/nemotron-3-${size.toLowerCase()}`, match: [`nvidia/NVIDIA-Nemotron-3-${size}-*`], developer: 'NVIDIA', origin: 'US',
    lineage: { ... }, licence: { id: '...', obligations: ['attribution'], inherited: [...] }, hosting: ['nearai-tee'], maxTier: 'T2' });
}
```
New local rows must add hosting class `local` and an exact `artifact` ({ format, sha256, quantization, remoteCode: false }), because `ARTIFACT_REQUIRED_CLASSES` refuses a T2 passport hosting `local` without one (`models.ts:59`, `369-373`). A row's id never changes in place; use a new id for a changed row. Catalogue types: `LocalCatalogueEntry` and `LocalArtifact` at `src/domain/gate/models.ts:127-141`; the parser (`parseModelsSection`, 485-538) needs the passport in the same section, `minFitBand` a token (`/^[a-z0-9][a-z0-9-]{0,31}$/`), 64-hex sha256, positive integer sizes.

### Hardware, download, disk (plans 02, 05)

**Analog:** `src/services/emergencyStop.ts` for the host module style: node built-ins imported first, then `vscode`; module-level state; atomic file work with `writeFileSync` plus `renameSync`.
```typescript

import * as path from 'node:path';
```

Download guard is exactly: `isEmergencyStopped()`, host allowlist, nothing else (`OutboundGuard` judges request text, not downloads). Write partials under extension storage `downloads/<id>.partial`, then rename. Inject `execFile`, `statfs`, clock and HTTP as seams so tests use fakes (fixture helpers in `src/test/helpers/`).

### The page (plan 11)

**Analog:** `src/services/policyEditor.ts` lines 231-290 and `media/policy/policy.{js,css}`. Pattern:

```typescript
const view = openPanel(host.context, { viewType, title, folder: PAGE, script: `${PAGE}.js`, style: `${PAGE}.css`, probe: PAGE,

view.webview.onDidReceiveMessage(async (message: unknown) => {
  try { await receive(message); } catch (error) { void view.webview.postMessage({ type: 'error', text: cut(...) }); }

async function receive(message: unknown) {
  if (typeof message !== 'object' || message === null || Array.isArray(message)) return;
```
