<objective>
The checks that make a local job count as viable (LMOD-06) and the measured numbers that replace estimates (LMOD-03): the tool-calling and embedding tests beside 32.1's one-word test, and the optional benchmark with its per-machine store. Decisions: D-22 (one-word test, tool-calling for standard and deep, vector length for embeddings, feeding 32.1's viability with no guide change), D-12 (fixed 512-token prompt, 128 tokens, three measures, stored per machine, server and artifact, "measured on {date}"), D-16 (Emergency stop applies), D-23 (the benchmark record). The embedding call is a small function here, not an interface change (RESEARCH "Fit and Speed", last paragraph).

Purpose: a model is offered for a job only after it actually did that job's kind of work on this server, and speed figures become facts when a person asks.
Output: two host files and two tests. Branch `feat/phase-32.2-07-tests-benchmark`.
</objective>
