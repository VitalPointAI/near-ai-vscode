## Shared Patterns

### Domain and host split
Pure modules in `src/domain/**` import nothing from `vscode`, `node:fs` or the clock. Node I/O in `src/gate/**` or `src/services/setup/**`; vscode only in the panel and registration files. Source: headers of `words.ts`, `proposal.ts`, `labelMapStore.ts`. The architecture scan (`src/test/helpers/architectureScan.ts`) enforces it; baselines are edited only in plan 20.

### Plain-words text
Sentences as exported constants, never built from untrusted data; no em dashes; say "your organization" (copy lint: `src/test/helpers/copyLintScan.ts`).

### Never block on failure
Logs and stores report once with a plain message and never throw into a decision (`WRITE_FAILED` in `src/gate/decisionLog.ts` line 28).

### Webview safety
One CSP, nonce scripts, `textContent` only, secrets never sent back to the page (`openPanel.ts`, `mcpView.ts` header).
