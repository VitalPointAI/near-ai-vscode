# Phase 32.1 Plan 06 summary

Plan 06 supplies the verified local prerequisites for the Get Started discovery tracer.

- Scans require confirmation and an exact plan for the current listed network and ranges. The host cap is 65,536 unique addresses and the rate is at most 50 address starts per rolling second. A single-token burst enforces that rate even when connections close immediately.
- Each attempt uses an injected connection with an 800 ms timeout. A port that closes at its timeout allows the scan to continue. A hung adapter or cancellation stops the run and leaves an end event.
- Network facts use fixed local inputs and reject missing or oversized output. An SPKI pin is collected during a TLS handshake with no application requests. Approval returns a proposal with the pin and keeps signed policy unchanged until the editor applies it.
