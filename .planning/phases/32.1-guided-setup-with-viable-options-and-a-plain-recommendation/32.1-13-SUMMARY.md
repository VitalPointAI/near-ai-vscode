# Phase 32.1 Plan 13: Get Started host summary

The Get Started controller drives the questions, checking, options, check page, Apply and landing. It reads your organization's policy only through the gate host. It builds route facts only from what each option's check observed, and recommends against the route policy narrowed by the proposed Canada answer. Before Apply it checks the chosen option again with fresh facts. Only `getStarted.ts` imports `vscode`.
