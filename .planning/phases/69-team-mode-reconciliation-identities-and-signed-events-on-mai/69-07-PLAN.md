<objective>
Move Team Mode from one key per device per team to one Ed25519 identity per person per install (D-06), create it under a lock on first need (Pitfall 4), and make Enable's rollback forget a key only when that call created it (D-22).

Purpose: Phase 70's first policy bundle on a fresh install, Phase 71's one persistent identity per member and Phase 80's signed answers all need a person-level key (TMR-05). This lands in PR 1 so the per-team key name never reaches main or a release; see the recorded choice in 69-01-PLAN.md. D-07 stays a rule; D-28 (one fingerprint visible on the remote, shared code-server installs) is recorded by plan 14.
Output: re-keyed `src/team/identity.ts`, Enable and session callers, adapted helpers and tests, and new D-22 and race tests.
</objective>
