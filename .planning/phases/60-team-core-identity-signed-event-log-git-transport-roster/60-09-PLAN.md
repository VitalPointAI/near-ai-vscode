<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| git error text -> UI (status bar, output, notifications) | Remote errors may include URLs with credentials |
| team state -> project audit file | Audit lives inside the project directory |
| remote content -> output channel | Event ids and reasons originate from attacker-controllable files |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-60-41 | Information disclosure | status tooltip and output lines | high | mitigate | redactGitMessage on every reason; canary password test on tooltip and output |
| T-60-42 | Denial of service | polling an unreachable or hostile remote | medium | mitigate | Exponential backoff to 10 minutes, single flight, pollSeconds clamped 5..3600 |
| T-60-43 | Spoofing | output channel lines built from remote data | low | accept | Only validated event ids (pattern-checked) or file paths and fixed reason strings are printed; no free text from bodies is echoed except validated names in the members list |
| T-60-44 | Tampering | changed team.json between sessions | high | mitigate | checkTrustPin at session start; mismatch stops the session with a plain message |
| T-60-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs in this plan; package.json unchanged |
</threat_model>
