<objective>
Prove the Team Mode architecture end to end with one thin, production-quality slice before anything expands from it: client A creates an Ed25519 device key (private half only in SecretStorage), signs a genesis batch (team.created + member.joined for the owner) over canonical JSON, commits it with git plumbing into a dedicated bare mirror as the orphan root of `refs/heads/near-ai/coordination`, and pushes it to a bare remote; client B, on a second clone with its own mirror, fetches the branch, reads the events in first-parent and file-name order, verifies them against the genesis anchor and materialises the same state byte for byte. Then lock the one-way canonical form (D-06) with exhaustive vector suites.

Purpose: canonical bytes, Ed25519 signatures and the git compare-and-swap ref are the three one-way architectural bets of the milestone (D-03, D-06). Proving them through real git on the first commit catches a dead end before eleven plans build on it. This plan also writes the complete type contracts (interface-first) so the wave 2 plans (60-02, 60-03, 60-04) can run in parallel against stable types.

Output: the team contracts, canonical JSON, policy defaults, device identity, runGit, the transport interface, a git transport that can create the genesis and read the log, a genesis-only materializer, the shared test harness and three test files.
</objective>
