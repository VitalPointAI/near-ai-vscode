# Phase 45.1: Validation Strategy

> Per-phase validation contract for 5 plans in 5 waves. Every test uses fictional organizations, partners, agreements, people and keys. Label values for NATO in tests are fictional placeholders, never real policy identifiers.

`nyquist_compliant` stays false: every task has an automated check written first, but 45.1-02 Task 1 is research checked by its file contents, and each test file is created by its own task (tests first).

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `node:test` through `scripts/run-tests.mjs` (root); `npm --prefix workbench test`; `deploy/test/openbao.test.mjs` |
| **Quick run (root)** | `flock "$HEAVY_LOCK" systemd-run --user --scope -q -p MemoryMax=4G -p MemorySwapMax=0 choom -n 1000 -- timeout 300 env NODE_OPTIONS=--max-old-space-size=1536 sh -c 'npm run compile && node scripts/run-tests.mjs dist/test/<file>.test.js'` |
| **Full suites** | 45.1-05 only, once each, one at a time |

Never bare `node --test` and never an uncapped `npm test`.

---

## Sampling Rate

- **After every task commit:** the task's own `<automated>` command.
- **After every wave:** the wave's new tests, `architecture`, `copyLint`, and the workbench tests when touched.
- **Blocking in every wave (release, crypto, data integrity):** the round-trip property test, binding tamper tests, `canExport` refusals (including the vetted, unvetted and missing vetting cases, D-12), TDF tamper tests, quarantine until a person accepts.
