# Phase 45.2 Plan 11: Label policy profiles with provenance Summary

**Label policy profiles now say where every value came from: a NATO draft from public sources, a Canadian DND/CAF draft that is honestly assumed with its OID left as a placeholder, a rule that keeps assumed values and placeholders out of operational exports, and a gap row on the road to production page for every value still waiting for its verified replacement and for each route to the acceptance trial.**

## The profile format as built (`label-profile/1`)

```ts
LabelProfile = {
  format: 'label-profile/1'; id; title;
  policyIdentifier: Leaf; uri?: Leaf;                       // uri: a urn:oid URN or a placeholder
  classifications: { value: Leaf; rank; marking?: Leaf }[]; // ranks 1 to 32, strictly ascending
  categories: { type: 'RESTRICTIVE' | 'PERMISSIVE' | 'INFORMATIVE'; tagName: Leaf; uri?: Leaf; values: Leaf[] }[];
  note: string }
Leaf = { value; provenance: 'verified' | 'public-unverified' | 'assumed'; source; date: 'YYYY-MM-DD'; gap?: 'G<n>' }
     | { placeholder; configurablePerTarget: true; provenance: 'assumed'; source; date; gap }
```

Refused when parsing, through the gate's shape helpers (`refused`, `checkKeys`; never spread): an unknown field anywhere, a missing or unknown provenance, a value that is not verified with no gap id, a gap id not of the form `G<n>`, a URI that is not a `urn:oid:` URN with digit arcs and no leading zero (placeholders excepted), a placeholder that is not `assumed`, duplicate or unordered ranks, duplicate classification values, tag names or category values (case-insensitive), a bad date (no roll-over), control characters, an unknown format.

- `valuesFor(profile, { classification: rank, releasableTo?, context? })` returns the policy identifier, URI, classification, top-level marking, the asked categories (tag, URI, values) and `used` (each value with its profile and path), with `lowestProvenance`. Context values are refused with "This label policy has no context values; they come with the mission's policy file." when the profile has none.
- `provenanceCheck(used, { purpose, exceptions, today })` refuses a placeholder for any operational export ("<placeholder> is not known for this target system."), refuses assumed values without an exception that names every assumed value of that profile and has not ended ("This export would use assumed label values (<profile title>). Your security officer can record an exception, or the values must be verified first."), and otherwise returns `lowestProvenance`, `shown` (each profile with its provenance) and `exceptionsUsed`.
- `withTargetOverrides(profile, { <path>: Leaf })` replaces placeholders only, for one target system, under the same value rules; the shipped profile is unchanged.

`src/domain/exchange/labelProfile.ts` is 436 lines and pure (it imports only `src/domain/gate/shape.ts`).
