# Phase 45.2: Validation Strategy

> Per-phase validation contract for 17 plans in 10 waves (amended 2026-11-25 with the inbound format adapters, 45.2-13 to 45.2-17, CONTEXT D-24 to D-35). Every test uses fictional organizations, partners, agreements, people, policies (`EXAMPLE-ORG`, `EXAMPLE-ALLIANCE`, never the texts' own example values) and keys; OIDs only under `1.3.6.1.4.1.32473` (RFC 5612). The public NATO policy identifier, OID and classification names appear only in `resources/label-profiles/nato.label-profile.json` and its test. No text, schema or example from an ADatP enters the repository (CONTEXT D-02).

`nyquist_compliant` stays false: every code task has an automated check written first, but 45.2-13 Task 1 (the record values, which replaced 45.2-07's checkpoint) and 45.2-12 Task 1 are a decision and an owner action, 45.2-10 Task 3 waits for the owner's gate approval, 45.2-04 Task 2 and 45.2-09 Task 1 depend on a disposable container that may not run on every machine, and acceptance needs a partner's KAS with its own samples (45.2-12).

## Sampling Rate

- **After every task commit:** the task's own `<automated>` command.
- **After every wave:** the wave's new tests, `architecture`, `copyLint`, the 45.1 exchange tests (`exchangeLabelInterop`, `exchangeLabelBinding`, `exchangeTdf`, `exchangeExport`, `staffExchange`), the inbound tests once they exist (`archiveZip`, `exchangeInbound`, `exchangeInboundTdf`, `exchangeInboundBdo`, `exchangeInboundMarked`, `exchangeInboundFuzz`), and the workbench tests when touched.
- **Blocking in every wave (security, crypto, data integrity):** the XML reader's refusals and fuzz test, the label round trips and the import join property test, the provenance rule (assumed values and placeholders in operational exports), the binding-tamper, certificate-path and signature-wrapping tests, the assertion replay test, the KAS listing and pinning tests, the classical-key cap and 2036 refusal, `canExport` refusals, quarantine until a person accepts; and, for the inbound adapters, the archive limits and zip-bomb tests, the no-I/O and no-release-signer architecture rule, the declared-checks test, the never-more-trusted and never-lower property tests, the fail-safe evidence tests (no conversion, a non-officer author, an unpinned or stale anchor, an anchor pinned for another partner), `REFUSAL_CLASS` completeness, the single-decrypt test with no SHA-1 retry, the SHA-1 and 2048-bit RSA refusals of 45.2-06, the refused-binding test, and the exchange-officer check on every decision.
