# Phase 45.2: Validation Strategy

> Per-phase validation contract for 10 plans in 8 waves. Every test uses fictional organizations, partners, agreements, people, policies (`ACME`, `MOCK`) and keys; OIDs only under `1.3.6.1.4.1.32473` (RFC 5612). No NATO label value, and no text, schema or example from an ADatP, enters the repository (CONTEXT D-02).

`nyquist_compliant` stays false: every code task has an automated check written first, but 45.2-07 Task 1 and 45.2-10 Task 2 are decisions and owner actions, 45.2-09 Task 1 depends on a disposable container that may not run on every machine, and the ZTDF acceptance check needs partner samples (45.2-10).

## Sampling Rate

- **After every task commit:** the task's own `<automated>` command.
- **After every wave:** the wave's new tests, `architecture`, `copyLint`, the 45.1 exchange tests (`exchangeLabelInterop`, `exchangeLabelBinding`, `exchangeTdf`, `exchangeExport`, `staffExchange`), and the workbench tests when touched.
- **Blocking in every wave (security, crypto, data integrity):** the XML reader's refusals and fuzz test, the label round trips and the import join property test, the binding-tamper and signature-wrapping tests, the assertion replay test, the KAS listing and pinning tests, `canExport` refusals, quarantine until a person accepts.
