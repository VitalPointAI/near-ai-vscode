## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Information Disclosure | activityStore serialization | high | mitigate | Persist operational metadata only, redact secrets/raw private prompts, and test serialized output for credential-shaped material. |
| T-03-05 | Tampering | reopen handler | medium | mitigate | Validate stable session IDs, handle corrupt records safely, and never treat stored text as executable command input. |
| T-03-06 | Denial of Service | activity ledger | medium | mitigate | Bound event/session counts and use atomic writes with recovery from partial/corrupt files. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package install is planned; retain the official-runtime package restriction from the preceding plan. |
</threat_model>
