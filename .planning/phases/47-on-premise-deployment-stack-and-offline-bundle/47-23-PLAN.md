<objective>
The system use notice (AC-8; D-76 in `47-COMPLIANCE-CONTEXT.md`): your organization's notice, configurable per language in the realm site file, shown on every sign-in page before the person signs in with their passkey or hardware key. Per D-70 (the owner's direction of 2026-11-24), the obligation is delivered as code and tests wherever possible.

Purpose: AC-8 needs the notice before access is granted and kept on screen until the person takes an explicit action to sign in. Keycloak's terms-and-conditions action shows only once per person, so the notice goes in the sign-in page itself.

Output: realm as code carrying the notice text, a minimal `sterling` login theme that overrides only `footer.ftl`, a small chart that delivers it as a ConfigMap, the Keycloak mount, and realm test cases.
</objective>

Facts (D-76 discovery, Keycloak 26.8.2 source):
- `keycloak.v2/login/template.ftl` imports `footer.ftl` and calls `<@loginFooter.content/>` on every page built with `registrationLayout`, which includes the passkey sign-in page `webauthn-authenticate.ftl`.
- `footer.ftl` is an empty `content` macro whose comment says to override it in a custom theme.
- `RealmRepresentation` has `localizationTexts`, a map from locale to a map from key to text; keycloak-config-cli's baselines carry it.
- `TermsAndConditions.evaluateTriggers` is empty, so that required action never repeats.

47-14 (wave 5) and the guest-accounts plan 47-19 (wave 6) also edit `realm.json`, `apply.mjs`, the realm site file and `realm.test.mjs`; this plan runs in wave 7 after both, so start from main after them. 47-20 (guest expiry, wave 8) builds on this realm.

Spike pattern: as 47-08's S6, Keycloak `quay.io/keycloak/keycloak@<digest from images.lock.json>` (`start-dev`) and keycloak-config-cli in podman on an internal network, under the memory cap and the heavy-run lock taken with `flock -o`, containers removed in the same run.

Default notice text (owner and legal to approve; D-76):
- `en`: "This is a restricted system. Use it only if you are authorized, and only for purposes your organization's policies allow. Sign-in and activity on this system are recorded and may be monitored and audited, and records may be disclosed to authorized investigators as the law allows. Unauthorized use may lead to disciplinary or legal action. Personal information collected here is used to manage access and is handled under your organization's privacy notice."
- `fr`: "Ce système est à accès restreint. Utilisez-le seulement si vous y êtes autorisé, et uniquement aux fins permises par les politiques de votre organisation. Les connexions et l'activité sur ce système sont enregistrées et peuvent être surveillées et vérifiées, et les enregistrements peuvent être communiqués aux enquêteurs autorisés dans les limites permises par la loi. - `realmSettings` reads `systemUseNotice`.

  - `supportedLocales`, the notice's languages;

Theme files:
- `files/theme.properties`: `parent=keycloak.v2`, `import=common/keycloak`.
- `files/footer.ftl`: redefines the `content` macro to render `msg("sterlingSystemUseNotice")`, split on blank lines into paragraphs, inside one element with id `sterling-system-use-notice` and role `note`. Keep FreeMarker's default HTML escaping switched on for the text, so it cannot inject markup.
