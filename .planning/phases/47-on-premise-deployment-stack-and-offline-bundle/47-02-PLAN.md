No npm dependency is added: deploy scripts and tests use Node built-ins only (research "Package Legitimacy Audit"); the scripts must run on Node 22 or later because a site's import host gets Node from its own OS repository.

Helm before 47-04 extends install-tool.sh: download `https://get.helm.sh/helm-v4.3.2-linux-amd64.tar.gz` and its `.sha256sum`, check the hash with `sha256sum --check`, and extract it into `compliance/out/tools/` so the binary is `compliance/out/tools/linux-amd64/helm` (the same path `sh compliance/ci/install-tool.sh helm compliance/out/tools` will produce). 47-01 writes the `helm` pin from the same official checksum.

Release descriptor format (fixed here; every later plan follows it): `deploy/values/<release>.release.json` with
- `chart`: a `charts.lock.json` name, or `path:<directory>` for a local chart;
- `namespace`; `order` (install order, integer);
- `values`: list of our values files; `site`: optional per-site values file under `deploy/values/site.example/`;
- `images`: list of `{ "lock": "<image name as listed in images.lock.json>", "set": { "<values path>": "<part>" } }` where part is one of `ref` (`<registry>/<sitePath>@<digest>`), `registry`, `repository` (sitePath), `digest`, `tagAtDigest` (`<tag>@<digest>` for charts that only take a tag);
- `enabledWhen`: optional object of site-global equalities (for example `{ "registryKind": "harbor" }`);
- `instances`: optional name of a site-global list; the release renders once per item (the hubs, 47-11);
- `secrets`: optional list of `{ "name", "kv", "keys", "generate" }` consumed by the install script (47-16).

Image lock format (fixed here): `deploy/bundle/images.lock.json` with `images` (third-party: `{ "ref": "<host>/<repository>:<tag>@sha256:<64 hex>", "component": "<D-53 id>" }`), `built` (ours: `{ "name": "sterling/<name>", "image": "deploy/images/<name>/image.json", "component", "digest": null | "sha256:..." }`) and `release` (published by another pipeline: `{ "name", "from", "digest": null | "sha256:..." }`). Only `images` is third-party and discovered by the checker (47-04).

Vocabulary: "your organization"; Sterling naming.
