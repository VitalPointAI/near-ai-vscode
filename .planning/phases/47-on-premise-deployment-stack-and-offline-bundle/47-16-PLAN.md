<objective>
The site install script (DEP-01 install from the bundle, DEP-06's unset-volume refusal, DEP-12's preflight): one Node script on the import host that checks the site file, re-runs the CI hardening checks on the site's own values, writes node files, makes the bootstrap CA, brings up the registry, imports the bundle, creates static secrets from OpenBao, and installs every release in order, stopping at the key ceremonies. Also records the digests the deploy-images workflow published.

Purpose: success criterion 1 (a site installs from one signed offline bundle) and the D-11, D-17, D-31 refusals that make an unsafe install impossible rather than merely documented.

Output: install.mjs, preflight and shared invariants modules, record-digests.mjs, the registry bootstrap tarball in the bundle, and the install test.

The apply step puts whichever of the three ConfigMaps the opensearch release renders, so it works before and after 47-24 merges.
- **Tool item versions (D-75).** Tool items in the manifest carry their pin's `version`, which 47-28's upgrade check reads.
