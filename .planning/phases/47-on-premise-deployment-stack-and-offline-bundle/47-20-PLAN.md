It then:
1. Gets a client-credentials token from Keycloak, with the client id and secret in the Basic Authorization header, never in a URL or argv.
2. Logs in to OpenBao `auth/jwt/login` with role `guest-expiry` and that token.
3. 4. Calls `expireGuests` with these clients.
5. Revokes its OpenBao token with revoke-self at the end.

The runner prints one line per guest ended. It exits non-zero when any side failed, still trying the other side. `--no-sessions` skips Kubernetes, for runs outside a cluster.
