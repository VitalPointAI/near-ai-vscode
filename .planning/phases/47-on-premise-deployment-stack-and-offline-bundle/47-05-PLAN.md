<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Site registry to kubelet | Images pulled by nodes |
| Pod creation to API server | Admission decides what runs |
| Pods to anything outside the cluster | Egress |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-47-14 | Tampering | unsigned or substituted image | critical | mitigate | Kyverno ImageValidatingPolicy with the organization's static key, failing closed; site-registry-only policy so an off-registry name cannot skip the glob |
| T-47-15 | Information disclosure | egress from pods | high | mitigate | egress-site-only NetworkPolicy in every namespace, coverage asserted by test; registries.yaml disables the default endpoint |
| T-47-16 | Repudiation | Session and Secret access | medium | mitigate | Audit policy records theia.cloud writes and Secrets at metadata; shipped to the site store by 47-10 |
| T-47-17 | Elevation of privilege | privileged namespaces | high | mitigate | PSA restricted by default; exemption list fixed at six namespaces and asserted by test |
| T-47-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed; RKE2 artifacts checked against SHA-256 pins on the node |
</threat_model>
