- `csr --out <file>`: asks OpenBao to generate the `pki_int` intermediate CSR (the key never leaves OpenBao) and signs the CSR file so HQ knows which site sent it. The HQ offline root signs it in the key ceremony (runbook 47-17), outside any network.
