## Decision records (one-way doors, adopted autonomously; review post hoc)

- **DR-13-05 Identity derivation (one-way, D-01):** entropy E = 32 random bytes = 24 English BIP-39 words (@scure/bip39 checksum). Use E directly (not BIP-39's PBKDF2 seed). salt = "near-ai-kb/identity/v1"; ed25519Seed = HKDF-SHA-256(E, salt, "ed25519", 32); mlDsaSeed = HKDF(E, salt, "ml-dsa-65", 32); xwingSeed = HKDF(E, salt, "x-wing", 32); localSecretsRoot = HKDF(E, salt, "local-secrets", 32). New purposes only add new info strings. fingerprint = SHA-256 hex of canonicalBytes({ alg: { sig: 'ed25519+ml-dsa-65', kem: 'x-wing' }, ed25519: b64, mlDsa65: b64, xwing: b64 }).
- **DR-13-06 Key file and KDF (costly; OQ9/A2):** scrypt N=131072, r=8, p=1, maxmem 256 MiB, 16-byte salt, async `crypto.scrypt` (never in activation); AES-256-GCM 12-byte nonce; AAD = canonicalBytes of every header field. Format `{ format: 'near-ai-kb-identity', v: 1, fingerprint, createdAt, kdf: { alg: 'scrypt', N, r, p, salt }, aead: { alg: 'aes-256-gcm', nonce }, ct, tag }`. scrypt counts as D-01's "equivalent" to Argon2id because Node 22 has no `crypto.argon2` and noble's Argon2 is unaudited; the `kdf.alg` id lets Argon2id be added when the engine floor moves. Default file name `near-ai-kb-<fingerprint first 8>.kbkey`.
- **Passphrase policy (OQ8, assumption):** at least 12 characters, or at least 4 space-separated words of 3+ characters; no strength-meter dependency.
- **Custody (D-03):** the key file in `<globalStorage>/kb-identity/<kbId>.kbkey` is always written. On a trusted keyring (macOS/Windows local desktop) the entropy may also be cached in SecretStorage under `nearAi.kb.identity.<kbId>.entropy`; a cache miss falls back to the key file, never to generation. `keyringTrusted` is false when `platform === 'linux'`, `remoteName` is set, or `uiKind` is web.
- **Never-overwrite rule:** an existing custody key file is never overwritten; if a restore finds it corrupt, it is renamed to `<name>.corrupt-<ISO timestamp>` (archived, not deleted) before the restored file is written.
