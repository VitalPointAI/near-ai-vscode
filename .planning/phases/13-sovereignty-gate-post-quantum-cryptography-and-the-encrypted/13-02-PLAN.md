## Decision records

- **DR-13-10 Mode record (costly):** globalState keys `nearAi.kb.record.<kbId>` (the record) and `nearAi.kb.path.<sha256(path.resolve(root)) first 32 hex>` (path index to kbId). kbId is a random 128-bit lowercase hex id that also appears in the genesis marker. Resolution: KB if a record is indexed for the path, OR the marker exists (readable or not), OR the session latch is set. A marker whose kbId matches a record re-indexes the new path (rename), state 'ok'; a marker with no record is 'unreconciled' (restricted until adopted with the recovery export in plan 13-11); a record whose marker is gone is 'base-missing'. There is no API that removes a record or sets a project to standard. Residual (accepted, A12): an agent with shell access could edit VS Code's state.vscdb; plan 13-04 makes shell commands naming it ask first.
- **Assumption (OQ6 defaults):** KB egress defaults are web search/fetch ON (SOV-03), MCP OFF, security scan (OSV.dev, endoflife.date) OFF until the user enables them per project (plan 13-10 adds the toggles).
- **assumption_delta:** `query assumption-delta scan 13` returned detected:false; "project mode" is introduced as `ProjectMode = 'standard' | 'kb'` in the domain without promoting it into other identities.
