## Decisions (Claude's discretion: wording)

- **ERASE_NOTICE:** `Erasing destroys this item's key, so its content becomes unreadable in this base and the log still verifies. Copies already read are not recalled, and backups made before now may still hold it.`
- **Agent tool:** name `KbEraseItem`, capability `workspaceWrite`, parameters `{ item: 32-hex id, explanation: string 10-500 characters }`; `risky()` always returns a reason (the agent loop asks even under fully-autonomous); `preview()` returns `{ kind: 'note', text }` with the item kind and id, the explanation (control characters stripped, length-bounded), and ERASE_NOTICE. Offered only when `request.kb` is set and not read-only. The tombstone `by` is `agent:<agent label>`.
- **User command:** pick an item from the open base (labels show kind and short id; the item title is shown in the picker only, never written anywhere), show ERASE_NOTICE in a modal, ask for a reason, then require typing `erase` to confirm; `by` is `user`.
