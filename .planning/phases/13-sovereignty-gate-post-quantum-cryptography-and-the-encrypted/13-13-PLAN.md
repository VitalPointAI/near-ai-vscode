## Decisions

- **KB transcript key:** `kbTranscriptKey(localSecretsRoot, kbId)` = HKDF-SHA-256(localSecretsRoot, salt = utf8(kbId), info = "near-ai-kb/transcripts/v1", 32); KB transcripts live in `<globalStorage>/transcripts-kb/<kbId>/` so they survive folder renames and never mix with SecretStorage-keyed transcripts. The existing `sharedTranscriptKey` path stays for standard projects.
- **KB activity vocabulary (KB_ACTIVITY_VOCABULARY):** one fixed phrase per event kind and status, e.g. `Session started.`, `Model call completed.`, `Tool call completed.`, `Agent started.`, `Agent finished.`, `Approval requested.`, `Run failed.`; ids, tool names, model ids, counts, costs, and token numbers are kept.
- **KB detection for sinks:** `isKnownKbRoot(root)` in kbMode.ts returns true when the session latch holds the root or `.near-kb/genesis.json` exists (raise-only, never lowers), so every ActivityStore built for a KB root redacts without each caller passing a flag.
- **Scan scope:** the workspace root (excluding only the seeded input file the user placed), the extension's global storage directory, and `os.tmpdir()` entries whose names start with `near-ai-`; forms: raw UTF-8, UTF-16LE, base64 at offsets 0/1/2, lower- and upper-case hex, JSON-escaped.
