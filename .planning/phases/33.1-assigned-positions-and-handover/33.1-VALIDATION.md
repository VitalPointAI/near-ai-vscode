# Phase 33.1: Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Codex's first version (2026-11-23) is replaced by this one for the native re-plan (33.1-CONTEXT.md, D-06 to D-25). Every test uses fictional people, positions, devices, keys and work areas in temporary stores and disposable containers.

`nyquist_compliant` stays false: every task has an automated check written first, but plan 12's container and Playwright run takes up to 2400 s, above the per-task latency target, and the wave 0 box stays open because each test file is created by its own task (tests first) rather than in a separate wave.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `node:test` through `scripts/run-tests.mjs` (root, Node 24); the hub's own run in `hub/` (Node 26.13.1); the workbench unit suite `npm --prefix workbench test`; the container and Playwright suite `npm --prefix workbench run test:container` (46-08, 33-30) |
| **Quick run (root)** | `flock "$HEAVY_LOCK" systemd-run --user --scope -q -p MemoryMax=4G -p MemorySwapMax=0 choom -n 1000 -- timeout 300 env NODE_OPTIONS=--max-old-space-size=1536 sh -c 'npm run compile && node scripts/run-tests.mjs dist/test/<file>.test.js'` |
| **Hub run** | `cd hub && flock "$HEAVY_LOCK" systemd-run --user --scope -q -p MemoryMax=4G -p MemorySwapMax=0 choom -n 1000 -- timeout 600 env PATH="$HOME/.nvm/versions/node/v26.13.1/bin:$PATH" NODE_OPTIONS=--max-old-space-size=1536 sh -c 'npm run build && node ../scripts/run-tests.mjs dist/test/<file>.test.js'` |
| **Workbench run** | `flock "$HEAVY_LOCK" systemd-run --user --scope -q -p MemoryMax=4G -p MemorySwapMax=0 choom -n 1000 -- timeout 600 env NODE_OPTIONS=--max-old-space-size=1536 npm --prefix workbench test` |
| **Full suites** | plan 12 only, once each, one at a time: root `npm run lint && npm test` (6G, 1800 s), hub `npm test`, workbench unit and lint, then the container run (6G, 2400 s) |
| **Estimated runtime** | root file under 60 s; hub file under 120 s; workbench unit under 300 s; container run about 40 min |

Never bare `node --test` and never an uncapped `npm test`.

## Sampling Rate

- **After every task commit:** the task's own `<automated>` command.
- **After every wave:** every new test file of the wave, `copyLint.test.js`, `architecture.test.js`, `replicaBoundaries.test.js`, and the hub files when the wave touched `hub/`.
- **Blocking in every wave that touches them:** authorization (who may post, report, decide, delegate), the personnel privacy boundary, key changes at handover, migration parity, and the person-key rule.
- **Before `/gsd-verify-work`:** plan 12's full suites and container run green once.
- **Browser checks (D-08):** blocking only for the passkey on Report for duty, a relieved workspace losing its actions, and the private unable reason; the rest are diagnostic.
