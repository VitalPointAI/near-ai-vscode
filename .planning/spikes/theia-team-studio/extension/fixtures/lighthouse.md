## editor
role: Documentation editor
tools: Read

Collect the source notes and turn them into a short exhibit guide using consistent terminology.

## accessibility-reader
role: Accessibility reviewer
reports-to: Editor
tools: Read

Read the draft guide for clear labels and understandable directions. Flag any instruction that depends only on color or location.

## visitor-notes
role: Visitor notes reviewer
reports-to: Editor
tools: Read

Check whether the draft answers the common visitor questions listed in the synthetic brief.
