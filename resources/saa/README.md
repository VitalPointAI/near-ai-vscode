# SA&A forms

The editable Word drafts are adapted from the project's supplier-prepared Government of Canada and DND SA&A worksheets. The public guidance and solicitation examples cited in the drafts describe the processes these worksheets support. The sponsoring authority determines which forms, profiles and routing apply to the deployment and supplies controlled departmental templates where required.

Start with the submission cover and routing form. Complete the Security Categorization Assessment Report (SCAR), tailored profile approval and security concept of operations (CONOPS) when required. Use the system security and privacy plan, operations plan and threat and risk assessment to document the proposed deployment. Use the assessment plan, assessment report and review, and the evidence requests and plan of action and milestones (POA&M) worksheets to record findings and actions. The authorization and residual risk worksheet is for the designated decision makers. The intake checklist and official forms register identify conditional procurement and privacy forms.

Use the package's `evidence/README.md` to identify the selected product baseline and available evidence. Use the security requirements traceability matrix (SRTM) and source evidence to assess individual controls. Enter deployment observations, approvals, signatures and handling instructions in the sponsor's approved repository.

The `official/` directory contains unaltered public Treasury Board forms, with issuing authorities and applicability in its [forms register](official/README.md).
