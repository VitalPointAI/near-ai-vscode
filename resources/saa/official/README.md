# Official forms register

These are unaltered blank English forms or, where indicated, links to the issuing authority. The contracting, privacy and screening tracks apply only when the relevant authority confirms a trigger. Complete those records in the approved process for that track. The product assessment package contains no completed screening or personal-information forms.

| Form | File or source | When it applies | Responsible party |
|---|---|---|---|
| TBS/SCT 350-103, Security Requirements Check List | [Official bilingual PDF](350-103-nf.pdf) | Procurement with contract security requirements | Project authority, departmental security authority, procurement and contracting security officials |
| TBS/SCT 350-65E, Privacy Checklist | [Official editable form](privacy-checklist-template-en.docx) | Departmental privacy intake and screening where required | Institution's program and privacy offices |
| TBS/SCT 350-66E, Privacy Impact Assessment | [Official editable form](privacy-impact-assessment-template-en.docx) | The institution determines a PIA is required under the applicable policy and standard | Institution's program and privacy offices with designated approval |
| TBS/SCT 350-67E, Personal Information Bank Submission | [Official editable form](personal-information-bank-submission-form-en.docx) | A bank must be registered, modified, transferred or terminated | Institution's privacy office |
| TBS/SCT 350-68E, PIA Web Summary | [Official editable form](privacy-impact-assessment-web-summary-template-en.docx) | The institution approves a PIA and prepares its applicable public summary | Institution's privacy office |
| TBS/SCT 350-69E, Privacy Protocol | [Official optional template](privacy-protocol-template-en.docx) | Applicable non-administrative use of personal information | Institution's privacy office |
| Request for Private Sector Organization Screening (PSOS) | [Official public form and instructions](https://www.canada.ca/en/public-services-procurement/services/industrial-security/security-requirements-contracting/submitting-requests-forms-other-documents/request-private-sector-organization-screening-form.html) | Contract Security Program sponsorship where requested | Approved sponsor only |
| Application for Registration (AFR) | [Official guidance and procurement route](https://www.canada.ca/en/public-services-procurement/services/industrial-security/security-requirements-contracting/submitting-requests-forms-other-documents/application-registration-form.html) | Supplier organization screening | Company security officer or authorized alternate, using the solicitation or screening package |
| Company security officer appointments, security agreement and personnel records | [Contract Security Program forms and routing](https://www.canada.ca/en/public-services-procurement/services/industrial-security/security-requirements-contracting/submitting-requests-forms-other-documents.html) | When the program or contracting authority requests them | Responsible security officer through the approved channel |
| Procurement requisition and bidder cover sheet | [CanadaBuys official instructions](https://canadabuys.canada.ca/en/buyer-s-portal/buyer-s-guide/plan/contract-security-and-privacy-requirements/security-solicitations-offers) | When prescribed by the solicitation or procurement process | Sponsor procurement officer using the Government of Canada network or departmental process |
| DND SCAR, tailored profile letter, routing, ATO or equivalent decision | [Editable project drafts](../editable/) | For the sponsoring DND project to confirm and replace with its own controlled forms if required | Designated departmental authorities |

Use the latest versions available through the authority when the package is submitted. The published DND contract specimen describes the expected deliverables for that engagement. DND's internal templates and authorized intake repository must be supplied or confirmed by the sponsor.
